# Claude exchange

Claude memories, chat transcripts and plans passed between the Mac (design chats) and the Linux machine (Agora, prototyping). Files are copied in as they were; nothing here is a source of truth, the bible and `docs/northstar/` are.

- `transcripts/`: Claude Code session logs (`.jsonl`), named `date_sessionid_topic`.
- `plans/`: plan files from `~/.claude/plans/`.
- `memory/`: memory files from `~/.claude/projects/*/memory/`.
