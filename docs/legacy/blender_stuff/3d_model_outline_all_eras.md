# Ouroboros Manifold — 3D Model Outline by Era

> **Purpose:** Starting-point brainstorm for 3D model content across all eras. Each era follows the bible's Era Creation Template (Layer 3: Unit Visual Progression, Layer 4: Tactical Map Structures). Units conform to cross-era silhouette archetypes (Raider = narrow/elongated, Interceptor = wide/flat, Vanguard = front-heavy wedge, Warden = radial/vertical, Bombard = longest/linear, Bastion = widest/compact). Three tiers per era follow the universal 0–33/34–66/67–100 boundaries.
>
> **Art style:** Low-poly, Art of Rally aesthetic. 200–500 polygons per model. Flat or minimal shading, clean geometric forms.

## 11. Colonial Mars

### Tier Identity
