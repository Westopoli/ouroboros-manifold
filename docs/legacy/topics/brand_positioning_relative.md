# Brand Positioning — Relative to Adjacent Strategy Anchors

## What this brief is

Brand-positioning synthesis for Ouroboros against the six primary-tribe anchors identified by prior research: Crusader Kings 3 (CK3), Wildermyth, RimWorld, Old World, Stellaris, Battle Brothers (BB). Brief maps where each anchor sits in the primary-tribe psychographic + tag-overlap + cluster space, identifies the unoccupied positioning slot Ouroboros can claim without cloning any single anchor, and surfaces the register (heroic / empire-building vs cyclical / archival / Foundation) per surface. Synthesises five upstream briefs: T-A1 (`primary_tribe_psychographic_profile.md`), T-A4 (`audience_overlap_map.md`), T-S1 (`steam_tag_overlap_2026.md`), `foundation_vocabulary.md`, `lieutenant_pivot_niche_brief.md`.

Brief feeds: Steam page capsule + short description + about-the-game copy, T-B2 author-voice signalling brief, T-B3 tagline / one-sentence-pitch patterns brief, all marketing surfaces (trailer, screenshot picks, festival pitch decks, press kit one-liner, creator-pitch copy), Design Lane brand-tone fork decisions.

**Does NOT recommend a pick.** Research Lane surfaces positioning slots, anchor-relative deltas, and register options. Design Lane + Westley pick which slot Ouroboros occupies, which register dominates which surface, and which conflict resolution path to take on the bible's L292 Fortnite reference. No "Ouroboros should be positioned as X" statements below.

## Anchor-by-anchor positioning map

Each anchor's brand-position signal is the combination of: tribe it owns, tag bundle it occupies, register it speaks in, and pitch-language it has trained the audience to expect.

### Crusader Kings 3

- **Tribe owned:** dynastic medieval grand strategy. Per T-A1, the dynasty-as-protagonist hook is the single recurring positive theme — players cite "the king is dead, long live the king" as the value proposition.
- **Tag occupation:** Grand Strategy / Strategy / Simulation / Politics / RPG / Multiplayer (small co-op) / Medieval / Historical. Per T-A4 + T-S1: TRUSTED Grand Strategy anchor; Paradox cross-buy makes CK3 the densest reviewer overlap with Stellaris.
- **Register:** mixed. Achievement titles ("World Conqueror," "Restoration of the Roman Empire") are heroic / empire-building register per `foundation_vocabulary.md`. Tooltip and event prose oscillate between heroic ("forge your dynasty") and archival ("the line ended with..."). The mix is part of CK3's broad reach.
- **Pitch-language:** "story generator," "your dynasty across centuries," "the king is dead, long live the king."
- **Negative-space signals:** late-game blob tedium, DLC monetization fatigue, UI overwhelm, combat is auto-resolve. The CK3 audience has a half-faction explicitly wanting "real battles" (per T-A1 negative-themes #4) which CK3 does not deliver. This is the **direct positioning gap Ouroboros' Lieutenant System pivot addresses** — adjacent without cloning.
- **Positioning takeaway for Ouroboros:** CK3 owns medieval dynastic grand strategy. Adjacent-not-cloning move is sci-fi setting + named-lieutenant tactical layer + collapse-rebuild run shape, holding the "world keeps moving" core but solving CK3's late-game-blob complaint via collapse and CK3's no-real-battles complaint via lieutenants.

### Wildermyth

- **Tribe owned:** procedural narrative + character-attachment + chapter-bounded tactical RPG. Per T-A1, "I got attached to my characters in a way no other game has done" is near-universal positive — closest existing precedent for what Ouroboros wants lieutenants to feel like.
- **Tag occupation:** RPG / Tactical / Turn-Based Tactics / Story Rich / Procedural Generation / Fantasy / Hand-drawn / Comic Book / Generations (Legacy mode). Per T-A4: Cluster A + B intersection.
- **Register:** primarily heroic ("Heroes / Legends / Wall of Heroes") with a Foundation-adjacent twist (heroes age, retire to the wall, become legends that haunt the world). Chapter titles are heroic but legacy framing edges archival.
- **Pitch-language:** "the world remembers your heroes," "your campaign is your story," "heroes who become legends."
- **Negative-space signals:** tactical combat shallow, event pool exhausts at 3-5 campaigns (chronicle-scale warning for Ouroboros), no real overworld strategy layer, endgame anticlimactic. Wildermyth audience explicitly wants overworld strategy — per T-A1 negative-themes #4 — which Wildermyth does not deliver. This is the **second direct positioning gap Ouroboros addresses** via the generational world-sim layer.
- **Positioning takeaway for Ouroboros:** Wildermyth owns chapter-bounded fantasy narrative tactical. Adjacent-not-cloning move is centuries-long civilizational arc + sci-fi setting + named-lieutenants-as-history-fragments, importing Wildermyth's character-attachment instinct into a world that persists rather than ending at chapter 3.

### RimWorld

- **Tribe owned:** colony-sim emergent-story sandbox. RimWorld is the genre-defining "story generator" — Tynan Sylvester's own pitch language entered the lexicon.
- **Tag occupation:** Colony Sim / Simulation / Survival / Base Building / Sandbox / Strategy / Story Rich / Procedural Generation / Top-Down. Per T-A4: Cluster B core.
- **Register:** archival-coded story-after-the-fact. "The colonists endured the cold." "Steve was eaten by a megasloth." Past-tense observational framing is RimWorld's signature.
- **Pitch-language:** "story generator," "your colony," "no two playthroughs alike."
- **Negative-space signals:** scale is colony (3-30 people), not civilization; setting is intentionally vague sci-fi-via-archotech mystery; no generational handoff at civilization scale.
- **Positioning takeaway for Ouroboros:** RimWorld owns small-scale emergent-story colony. Adjacent-not-cloning move is scale jump from colony to civilization (lieutenants instead of colonists, regions instead of buildings, centuries instead of seasons) while keeping the archival "story emerged" register. The Foundation-tribe Asimov reference for civilization-as-specimen is where Ouroboros differentiates from RimWorld's deliberately fuzzy archotech setting.

### Old World

- **Tribe owned:** dynastic 4X historical antiquity. Per T-A4: Cluster A + C strongest pair-overlap with CK3 (7-9 shared tags, 40-55% estimated reviewer cross-ownership).
- **Tag occupation:** Strategy / Turn-Based Strategy / 4X / Historical / Grand Strategy / Politics / Family / Turn-Based Tactics / Hex Grid. TRUSTED Turn-Based Strategy anchor per T-S1.
- **Register:** heroic / empire-building dominant ("Conquer X cities," "Found Y wonders") with family-and-character layer that softens toward dynastic register.
- **Pitch-language:** "Civ meets CK3," "your dynasty leads an empire," "build an empire that lasts." Per T-A4: "centuries of consequence," "decline" framing — Old World is one of the few Cluster A+C anchors that talks explicitly about empires rotting.
- **Negative-space signals:** Old World is the **closest commercial reference for Ouroboros' shape minus the lieutenant-tactical layer**, per `lieutenant_pivot_niche_brief.md` Genre-fusion-attempts paragraph. Sales tier 300k units. Bronze-age / classical antiquity setting; no sci-fi.
- **Positioning takeaway for Ouroboros:** Old World owns dynastic 4X antiquity. Adjacent-not-cloning move is far-future sci-fi setting + lieutenant-tactical layer + collapse-rebuild as run shape rather than decline-as-late-game-curve. Old World's "Wrath of Gods" expansions are heroic register; Ouroboros' Foundation overlay can split register per surface to differentiate.

### Stellaris

- **Tribe owned:** cosmic-scale grand-strategy 4X sci-fi. Per T-A4: highest single-pair audience overlap in the matrix is CK3 ↔ Stellaris (50-65% reviewer cross-buy via Paradox catalog).
- **Tag occupation:** Grand Strategy / Strategy / 4X / Space / Sci-fi / Simulation / Real Time w/ Pause / Multiplayer / Exploration / Sandbox. Per T-S1: Sci-fi setting tag is high-reach (~$960M Steam net revenue) but carries space-RTS contamination unless filtered.
- **Register:** mixed-leaning archival — fallen-empires lore, end-game crises, "cosmic awe" framing all sit Foundation-adjacent. Mid-game empire builders speak heroic register; late-game crises speak archival.
- **Pitch-language:** "your empire among the stars," "civilizations rise and fall in the long dark," "explore strange new worlds." Per T-A4: Stellaris is the bridge anchor where Cluster C (grand strategy) meets sci-fi.
- **Negative-space signals:** per `lieutenant_pivot_niche_brief.md` — many Stellaris players are explicitly bored with current Stellaris content. Real-Time-with-Pause is risky as a tag-adjacency per T-S1. Stellaris is broad-cast 4X, not character-driven.
- **Positioning takeaway for Ouroboros:** Stellaris owns cosmic-scale grand strategy. Adjacent-not-cloning move is human-scale lieutenants + collapse-rebuild centuries + Foundation literary thematic anchor (which Stellaris's deliberately vague flavor avoids). Ouroboros can take the cosmic-awe register from Stellaris but anchor it in named characters and a single civilization across cycles, not many simultaneous empires across one cycle.

### Battle Brothers

- **Tribe owned:** permadeath roster-attachment tactical sandbox. Per T-A1: "Lost Hans the two-handed expert, cried." Closest existing precedent for the **stakes** Ouroboros wants lieutenants to carry.
- **Tag occupation:** Turn-Based Tactics / Tactical / RPG / Strategy / Procedural Generation / Permadeath / Medieval / Difficult / Open World. TENTATIVE Turn-Based Tactics anchor per T-S1.
- **Register:** functional / hardcore-respecting. "Your company. Your story. Your loss." BB's register is anti-glory — closer to journalistic / observational than either heroic or archival, but the audience reads BB stories as archival ("I'll tell my kids about Hans") even though the prose is bare.
- **Pitch-language:** "your mercenary company," "permadeath roster," "the world doesn't care if you die." Per T-A1 cross-cutting-finding #1: BB shares the "world keeps moving" pitch with CK3 + Wildermyth + FoG: Empires.
- **Negative-space signals:** functional-ugly UI (BB owns it, but it bounces accessibility-seekers); no narrative arc / no campaign; late-game contract-grind. The BB audience explicitly buys for sandbox-no-story per T-A1 negative-themes #4 split.
- **Positioning takeaway for Ouroboros:** BB owns medieval permadeath mercenary tactics. Adjacent-not-cloning move is scaling permadeath stakes upward (lieutenants commanding regions, not mercs commanding squads) + civilization context (story-rich, not sandbox-only) + sci-fi setting. Ouroboros borrows BB's permadeath-respect-for-the-audience stance, not BB's mercenary-roster shape.

## Cluster-relative positioning slot

Synthesising T-A4 clusters with the per-anchor maps above:

- **Cluster A (dynastic / generational strategy):** CK3, Old World, Wildermyth, BB. Common ground: characters who outlive you, names that matter generations later, dynasty / family / lineage framing. **Ouroboros sits inside this cluster** but offers what no anchor offers: full civilization-scale generational arc (BB is mercenary company, Wildermyth is chapter, CK3 is dynasty within map, Old World is dynasty within game-length).
- **Cluster B (emergent-story simulation):** RimWorld, Wildermyth, BB. Common ground: procedural-narrative depth, "no two playthroughs alike," story-after-the-fact framing. **Ouroboros sits at the edge** — has procedural emergence at world-sim layer + chronicle layer, but lieutenants are designed-personality not pure-procedural roll (per `docs/bible/game_bible.md ## In Flux`).
- **Cluster C (grand strategy spatial):** CK3, Old World, Stellaris. Common ground: grand-strategy scale, decades / centuries of decisions, shape history. **Ouroboros sits inside this cluster** at the smaller, more character-driven end — closer to Old World's scale than Stellaris's.
- **Outlier (shared-world war MP):** Foxhole, HD2. Ouroboros is bible-locked SP-first; explicitly outside this outlier per T-A4 + T-S1 banned bundle.

**Ouroboros' unoccupied slot:** the **A ∩ B ∩ C intersection with Stellaris-via-sci-fi bridge** — no current commercial title occupies the intersection of full-civilization-scale generational arc + emergent procedural narrative + grand-strategy spatial scope + sci-fi (Foundation-coded) setting + named-character tactical layer. The closest comparator is "Old World plus sci-fi plus lieutenant-tactical plus collapse-rebuild" — which is precisely the bible-locked shape.

This slot is **adjacent-not-cloning to all six anchors simultaneously**: Ouroboros borrows the generational hook from CK3, the character-attachment instinct from Wildermyth, the archival emergent-story register from RimWorld, the dynastic 4X structure from Old World, the cosmic-scale sci-fi register from Stellaris, and the permadeath-respect-for-the-audience stance from BB — while cloning no single one and competing directly against none.

## Register choice per surface

Per `foundation_vocabulary.md`: two registers are in scope. Heroic / empire-building (genre default, CK3 + Old World achievement-name anchored) vs cyclical / predictive / archival (Foundation tribe, RimWorld lore + Stellaris fallen-empires + Wildermyth Wall-of-Heroes anchored). The vocabulary scan flagged Chronicle as already locked Foundation-register, achievement names as the highest-leverage Foundation-register lever, and era-naming as a load-bearing future choice.

Cross-referencing against the cluster map:

- **Capsule + short description (Steam page primary surface):** Cluster A union pitch-language ("world keeps moving," "your dynasty / your civilization," "characters who outlive you") per T-A4. Register is mostly Foundation-leaning — "civilization across centuries" reads archival; "shape your dynasty" reads heroic. Per-surface register discipline (per `foundation_vocabulary.md` cross-cutting finding #1) means capsule must commit one way or the other. **Two valid options:**
  - **Option A — heroic-dominant capsule:** "Forge a civilization across centuries; name the lieutenants who outlive their commanders." Reads CK3-adjacent + Wildermyth-adjacent. Catches Cluster A's broader audience.
  - **Option B — archival-dominant capsule:** "A civilization rises, falls, and rises again. The chronicle remembers the lieutenants who shaped each cycle." Reads RimWorld-archival + Foundation-coded. Catches Cluster B + secondary Foundation tribe more cleanly.
  - **Neither is recommended.** Trade-off: heroic broader reach within primary tribe, archival sharper Foundation-tribe signal. Design Lane decides.

- **Achievement names:** per `foundation_vocabulary.md` cross-cutting finding #2, achievement names are the highest-leverage Foundation-register lever — Steam reviewers and Foundation tribe both pattern-match on achievement lists. Heroic ("Conqueror of the Settled Reach") vs archival ("Recorded the Fall of the Third Cycle") signals hard. Bible Chronicle commitment plus collapse-rebuild Tier-1 run-shape both lean archival register here.

- **Lieutenant names + lieutenant chronicle entries:** lieutenants are inevitable heroic-register pull (named characters with personality). Per `foundation_vocabulary.md`: "the chronicle records what each lieutenant did; the player commands but does not become them." Split-register strategy — chronicle's archival voice retells lieutenant heroic acts — preserves Foundation-tribe signal at the meta-narrative layer while letting lieutenants themselves feel character-driven.

- **Era names (per-era DLC):** per-era DLC ladder is bible-locked monetization shape. Era-naming convention is a tribe-signal lever. "Age of X" reads heroic; "Epoch N" reads archival; "Era of Y" reads neutral. Cross-references T-M2 (`per_era_dlc_structure.md`) per-era DLC structure decisions.

- **Trailer + tagline (T-B3 territory):** capsule register pick (above) cascades to trailer voiceover register and tagline pick. T-B3 explores tagline-pattern precedents.

- **Author-voice / dev blog tone (T-B2 territory):** independent of capsule register — author-voice can be archival ("the world remembers") OR plainspoken-craftsmanly (Tynan Sylvester, Worldwalker) OR aesthetic-uncompromising (HighFleet, Songs of Syx). T-B2 covers this.

## Conflict surfaced

### Conflict #3 — bible_monetization.md L292 Fortnite cosmetic-model reference

Per `lieutenant_pivot_niche_brief.md` and prior briefs, bible_monetization.md L292 cites Fortnite as a cosmetic / battle-pass / seasonal monetization reference. Cross-checking against this brief's positioning synthesis:

- **Tag-co-occurrence collision (T-A4):** Fortnite shares zero meaningful tag overlap with any of the eight anchors in the cluster matrix. Per T-A4 conflict section: Fortnite-coverage press signal is not the same audience as primary-tribe strategy-coverage signal.
- **Tribe-psychographic collision (T-A1):** primary tribe is anti-AAA-aesthetic, pro-authorial-voice, pays $25-35 specifically to AVOID Fortnite-shaped monetization. Per T-A1 Conflict-surfaced section: "primary tribe psychographic is anti-Fortnite-aesthetic. None of CK3/Wildermyth/BB/FoG:E community discourse positions Fortnite favorably; references in negative reviews typically as pejorative ('don't make this Fortnite')."
- **Register collision (`foundation_vocabulary.md`):** Fortnite-flavored monetization invokes seasonal-event live-service register (chapter / season / battle-pass / cosmetic-skin / pop-cultural-crossover). This register is neither heroic-empire-building nor archival-Foundation — it is a third register entirely (live-service / pop-cultural) that pulls a fourth tribe (Fortnite / Apex Legends / Roblox demographic). T-A4 identifies this as outlier-cluster territory, audience-disjoint from primary tribe.
- **Positioning-slot collision:** Ouroboros' unoccupied positioning slot (A ∩ B ∩ C + sci-fi + lieutenant-tactical + collapse-rebuild) is defined precisely by what Fortnite is not. Adopting Fortnite-framed monetization mechanics is not necessarily fatal (CK3 + Stellaris run DLC seasons that bear surface resemblance to season passes), but adopting Fortnite-framed monetization *language* in any audience-facing surface is a positioning collision.

**Three resolution paths preserved (per prior briefs T-M3 + plan conflict-flag #3):**

- **Path 1 — bible cleanup:** strike L292 Fortnite reference from bible_monetization.md; treat as marketing-artifact / historical-reference-only. Audience-facing surfaces never invoke Fortnite. Internal monetization mechanics (per-era DLC, cosmetic banner / unit-skin packs if any) can still draw mechanically from Fortnite season-pass shape without using the language. **Lowest positioning risk.**
- **Path 2 — limited surface invocation:** allow Fortnite-mechanic reference inside internal dev blogs / investor decks / GDC talks (Path 2's "tell crafters how the sausage is made" stance), bar it from all consumer-facing surfaces. **Medium positioning risk.**
- **Path 3 — full invocation as differentiator:** position Ouroboros as "Fortnite-style infinite eras meets Crusader Kings dynasty." **Highest positioning risk.** Per T-A1 + T-A4: collides with every primary-tribe anchor's audience expectation. Would require active reframing of the primary tribe ("we are pulling Fortnite players into strategy") which neither T-A1 nor T-A4 supports as feasible.

Bible authority resolves. Research Lane only surfaces. Cross-reference: `docs/research/topics/cosmetic_monetization_niche.md` (T-M3) covered the cosmetic-monetization dimension; this brief covers the positioning-language dimension.
