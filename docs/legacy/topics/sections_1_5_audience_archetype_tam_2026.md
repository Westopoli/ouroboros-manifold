## Section 5 — Direction read + decision tree

### What the evidence locks (TRUSTED)

1. **Pivot direction held.** All four originating-brief tier estimates (generational 80–200k, Foundation 20–80k, survival halo 200–500k, indie-curiosity 50–150k) survive multi-source cross-check.
2. **RTS framing remains banned.** Four kill-zone titles inside 12 months. No evidence the kill-zone is closing.
3. **TRUSTED rave-cluster = lieutenant pivot's design hook:** named characters with personality + emergent narrative from interlocking systems + long-term consequences. Closest commercial proof: **Old World**.
4. **TRUSTED rage-cluster = design landmine the build must avoid:** UI hides info + event-pool repetition + RNG-not-feeling-fair.
5. **Tag bundle locks:** Grand Strategy + Strategy + Story Rich + Sci-fi + Singleplayer + Simulation + Procedural Generation + Turn-Based Strategy. **Lead-tag combo = Grand Strategy + Turn-Based Strategy (500k–1.5M reach, no RTS contamination).**

### What the evidence does NOT lock (still open Design Lane forks)

- **WS5 Fork 1 (Run Shape).** Topic B + C narrow the field — narrative depth + procedural generation + long-form consequence all favored — but no single run-shape archetype is forced.
- **WS2 (MP).** Foxhole TRUSTED rave (persistent thousands-player scale + player-built logistics) opens an MP fork; Foxhole TRUSTED rage (solo-vs-clan misery + time-grind) closes the naive-MP version. Decision deferred to MP archetype work.
- **Foundation overlay depth.** TENTATIVE — Isaac Arthur reach proves the audience exists, but raw thematic-buyer conversion remains unmodeled (Topic E open).
- **Wishlist→purchase conversion modeling.** Topic D open.

### Decision tree

```
Q: Does the combat loop ship Turn-Based?
├── YES  → promote Turn-Based Tactics to PRIMARY tag bundle
│         → unlock 500k–1.5M reach combo (GS + TBS), the strongest TRUSTED combo
│         → directly answers FoG:E + CK3 TRUSTED rage ("cannot conduct battles" / "warfare is numerical")
│
└── NO   → stay on Turn-Based Strategy only; lieutenant decisions handle the tactical voice
          → tag bundle holds; reach combo holds at GS + Story Rich (200–500k)
          → must ship a non-RTS pause/intervene loop or the tactical-disempowerment rage re-fires

Q: Does the lieutenant cast age / die / retire across the run?
├── YES  → Wildermyth + Massive Chalice + CK3 + Old World rave-cluster all activate
│         → generational continuity column lights up = 4 STRONG audience pools
│         → must solve event-pool repetition (Wildermyth + Massive Chalice TRUSTED rage)
│
└── NO   → drop the generational-continuity column in Section 2
          → fallback to BB-style permadeath squad attachment only
          → cuts ~2 TRUSTED audience pools out of the addressable set

Q: How is MP framed on the store page?
├── PRIMARY tag  → re-triggers RTS-adjacent buyer expectations; contamination risk
│                  → BANNED per Topic C TRUSTED evidence
├── SECONDARY tag (async/co-op only) → safe; Foxhole-flavored persistence allowed
└── ABSENT       → safest; CK3 audience plays solo and converts highest

Q: How is the Foundation overlay messaged?
├── LEAD with Foundation framing       → narrow audience to TENTATIVE 20–80k thematic

```
