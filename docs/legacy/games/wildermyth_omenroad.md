# Wildermyth — Omenroad DLC (Worldwalker Games, 2024)

## Verified facts

Omenroad is the first and only major paid DLC for Wildermyth. It released in 2024, adding a roguelite-influenced endless dungeon mode ("the Omenroad") featuring new enemies, transformations, and a distinct mechanical structure from the base game's campaign model. Confidence: REPORTED (release fact and feature set from training data; exact release date — likely mid-2024 — not independently verified at capture. Confidence: REPORTED with caveat that the release may have been late 2023 or 2024; training data places it in 2024).

**Price:** Omenroad launched at **$9.99 USD**. Confidence: REPORTED (price from training data; not independently verified at capture).

**Base game context:** Wildermyth base game (reviewed in G-15 / existing wildermyth.md card) holds approximately 97% positive Steam reviews across 11,000–13,000 reviews with a $24.99 base price and lifetime sales estimated at 500,000–1,000,000 units. Confidence: REPORTED (figures from existing research card; see wildermyth.md for sourcing notes).

**Omenroad review status:** As of training data, Omenroad carries a "Very Positive" Steam review status, with a smaller review count than the base game (consistent with typical DLC attach patterns where DLC reviews are a fraction of base game reviews). Exact count: AMBIGUOUS — training data does not provide a reliable figure for Omenroad's independent review count separate from base game.

**Mechanical distinction:** Omenroad introduces a roguelite endless-mode structure that departs from the base game's authored-campaign model. This is a meaningful design deviation — it targets players who had exhausted the five authored campaigns and wanted replayable content, not additional authored narrative in the base game's style. Confidence: REPORTED (design framing documented in Worldwalker's own release communications and press coverage).

**Reception nuance:** Community reception noted that Omenroad appeals strongly to the "want more Wildermyth" hardcore base but is a weaker sell to players whose attachment was specifically to the authored-narrative campaigns. The roguelite structure is mechanically rich but narratively thinner than the base game's authored content. Confidence: REPORTED (community discussion pattern from training data).

**Attach rate:** Not publicly disclosed. AMBIGUOUS — Worldwalker Games has not published DLC attach figures. Given the base game's estimated 500k–1M units and the $9.99 price point, a reasonable indie-scale estimate would be 10–25% attach from active players, but this is entirely ESTIMATED and should not be used as a hard figure.

**Worldwalker Games studio size:** Small team (2–5 core developers). The DLC represents a meaningful development investment relative to studio size. Confidence: VERIFIED (studio size is public record from developer notes and interviews).

## Role in Ouroboros research

Omenroad is the **small-team single-DLC attach signal** in the research set — the only data point for what happens when a well-loved indie game with a strong review reputation releases a single major DLC.

Key signals for Ouroboros:

1. **Price ceiling at $9.99 for a small-team DLC add-on.** Worldwalker priced Omenroad below the base game ($24.99) and below the standard expansion tier ($19.99–$29.99). At $9.99, it sits in the "easy yes" zone for fans of the base game. This pricing discipline is relevant for Ouroboros' lower-tier era DLCs — if individual era packs are priced at $7.99–$9.99 rather than $14.99–$19.99, the attach math changes materially.

2. **Roguelite-vs-authored tension is a design fork risk.** Omenroad chose a replayable roguelite mode rather than additional authored campaigns. For a game whose identity was authored narrative depth, this was a safe mechanical bet (roguelite infinite replayability) but a partial identity misalignment. The "Very Positive" (not "Overwhelmingly Positive") reception relative to the base game's "Overwhelmingly Positive" is consistent with a DLC that landed well but didn't fully inherit the base game's identity magic. For Ouroboros, this is a warning signal: DLC that extends the game's core identity (new era, new civilization arc) will likely attach better than DLC that introduces a mechanically adjacent mode.

3. **Single-DLC small-studio model.** Worldwalker has (as of training data) released one DLC, not a catalog. This is consistent with a small-team studio that cannot sustain a continuous DLC cadence. If Ouroboros' planned 7-era ladder requires one DLC per year over seven years, that is a higher cadence than Omenroad demonstrates is feasible at small-studio scale without significant team growth.

4. **The "beloved base game" ceiling.** Omenroad demonstrates that even a beloved base game ($24.99, ~97% positive) does not guarantee strong DLC attach. The DLC requires its own merit argument — "this extends what you loved" is a stronger pitch than "this is new content in the same universe."

## Pattern observations

**Price point discipline:** $9.99 for a single-game-mode addition from a small studio. Below the expansion tier, above the cosmetic tier. Positions the DLC as a content purchase, not a cosmetic gesture, without the sticker-shock risk of a $19.99 price for an indie DLC.

**Single-SKU simplicity:** One DLC, no bundle, no pass, no season pass. This is the simplest possible DLC ladder (one rung). For Ouroboros, this represents the floor case — the minimum viable DLC catalog shape.

**Mechanical deviation risk:** Roguelite mode introduces replayability but departs from the authored-narrative identity. The design lesson is that DLC extending core identity (more authored campaigns) would likely have stronger attach than a mechanically adjacent mode for a narrative-identity game. Whether Omenroad would have attached better as "Campaign 6: authored narrative in Wildermyth's style" is an open question, but the reception pattern suggests the community wanted exactly that.

**Review count decay:** DLC reviews are a fraction of base game reviews — consistent with the general pattern that DLC review counts are 10–30% of base game review counts even at high attach rates. This is expected and not a negative signal about Omenroad specifically.

**No established cadence:** Omenroad is (as of training data) Worldwalker's only DLC. No pattern of annual or semi-annual releases exists. This confirms the small-team constraint: one quality DLC over three years of post-launch support.
