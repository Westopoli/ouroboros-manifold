# 1980s Era — Sloyd Prompt Batch Sheet

> Copy-paste prompts into Sloyd, mark off when accepted.
>
> **Era identity:** Late Cold War, circa 1980–1991. Tier 1 = Surplus (WWII/Korean War hand-me-downs, mismatched paint, riveted hulls, analog everything). Tier 2 = Superpower Client (standardized NATO or Soviet Bloc equipment, proper camo, professional military). Tier 3 = Cutting Edge (stealth geometry, smart weapons, satellite uplinks, late Cold War tech that's almost sci-fi).
>
> **Layer mapping:** 5 tactical layers. Layers 4–5 (deep/shallow water) = submarines. Layer 3 (surface) = ships and land units. Layers 1–2 (high/low air) = aircraft.
