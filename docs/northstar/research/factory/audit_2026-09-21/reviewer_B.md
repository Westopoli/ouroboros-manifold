## 3. Hardware and scheduling

**F-3-1: Two-slot pipelining needs a process model the dispatcher lacks.**
Unit: `flock -n /tmp/agora.lock … next.py; sleep 60` (service:12); `next.py:2-7` "run exactly ONE unit of work, then exit". `build.py:1056 _intervene` blocks the whole run, up to 2 × 300 s per call (`agy_client.chat timeout=300`) × `MAX_INTERVENTIONS=3` = 30 min of GPU-idle inside "BUILDING". "Next independent card runs while diagnosis proceeds" (PLAN:153) requires two concurrent processes and a lock split; not listed in Wave 1 or 3.
Severity: serious. Fix: name it: GPU-slot process + CPU-slot process, two locks, build.py split at intervene.

**F-3-2: A9's "52 min building per shipped card" includes cloud waits, so GPU throughput is unknown and PX-16 inherits it.**
A9:19 BUILDING = "worker/driver process running"; intervene timeouts, agy retries, worktree/`make`/regression all inside. `candidates.jsonl` has no timestamps (PX-19 §1). PX-16 replays `wall_minutes` per cycle.
Severity: minor. Fix: per-phase timestamps in candidates.jsonl before any new projection.

**F-3-3: CPU slot is not free; per-card CPU budget unstated and contends with the partially-offloaded model.**
Per C card: regression 32 s (measured) + mutation 50-95 s (PX-06) + 4 determinism builds/runs (gcc/clang × O0/O2) + UBSan + ASan builds/runs (~2-3× suite each) + "sampled memcheck" (valgrind 20-50×: 10-25 min if whole suite) → 3-6 min without memcheck, 15-30 with. Same slot also hosts prep, gate cards, T1 QA, replays. qwen3-coder:30b at 18 GB on 12 GB VRAM decodes ~6 GB from system RAM on CPU; CPU-slot pytest slows the GPU slot.
Severity: serious. Fix: publish a per-card CPU budget; memcheck only in the empty-chain list; measure contention once.

**F-3-4: Resident 18 GB model + Godot T2 sessions on one RTX 3060 not reconciled.**
`keep_alive: -1` pins ~12 GB VRAM; T2 QA (Xorg-on-NVIDIA recipe, SCORECARD D row) renders on the same card; vision "a local model only if it measurably fits beside the worker" (PLAN:147) already admits the squeeze but says nothing about Godot. Every QA session → eviction + 47 s reload.
Severity: serious. Fix: state the eviction policy; measure a Godot headless + resident 30B run.

**F-3-5: Windows gate is a human-operated, twice-weekly, unbuilt path that blocks every epic gate.**
D2: "epic gate cannot close without a passing Windows run"; VM Tue/Thu, 16.6 GB, booted by Westley. `Makefile:17-19` flags are GCC syntax (`-fexcess-precision=standard -mfpmath=sse`); no MSVC/clang-cl target, no Windows pytest/ctypes harness, no DLL build. Epic cadence ≤ 2/week and every close needs Westley's hand → violates the routing rule.
Severity: serious. Fix: Windows gate as an empty-chain-list item with its own runbook, not an epic-gate blocker, until a machine exists.

**F-3-6: Worker context overflow risk with no pre-call counter.**
`build.py:887 num_ctx=16384, num_predict=8192`; PX-19 §2 measured 47,681 chars (~12k tokens) for 208a1 with full header; `ollama_client.py:34-35 shift:false, truncate:false` → HTTP 400 → "crash" candidate, no hint to the model. No token count before the call (PX-19 §2).

## 4. Reward hacking and gate holes

**F-4-1: Fence is file-level, not function-level; worker can add arbitrary functions and includes.**
PLAN:110 "Only the named function(s) in one file change". Code: `build.py:959-961 changed != [snippet_file]` (file); `merge_reply_c` hoists any new top-level definition (`:282-298`, `_C_TOPLEVEL_DEF`) and any `#include` (`:274-280`). 594 of 630 `lib.om_*` symbols tests call are undefined anywhere in csrc (my census; `card_lint` ABI_GAP on 271a1) — a worker may define any of them in its file, making later cards "already satisfied" (203b2 precedent) or implementing another card's scope. Signature check applies only to named functions.
Severity: serious. Fix: reject hoisted non-static definitions; allowlist includes; diff must be ⊆ named function spans + static helpers.

**F-4-2: Control liveness runs at queue time only; nothing re-checks liveness against the candidate at merge.**
PLAN:141 + R10.1 "at queue time". R12 shows a repair silently killed a control. A worker writing `if (w->inject) { garbage }` makes every control "flip" while the correct path stays unconstrained; liveness "does not assume a direction" (`control_liveness.py` docstring).
Severity: serious. Fix: liveness on the story's controls in the merge gate, plus a direction assertion per control.

**F-4-3: Escalator test-fix gate cannot distinguish "filter out a confound" from "filter out the bug".**
Gate = assertions preserved + still red at stub + fixture detectors clear (PLAN:123). A `target_idx == 1` filter (R7f) passes all three by construction; so does a filter that excludes the failing record for a real defect. `test-defect` is assigned by the verifier/escalator itself.
Severity: serious. Fix: filter fixes require the excluded records to be asserted explicitly (count + why), or route filters to the day-side ledger.

**F-4-4: Escalator parent patches skip mutation, shadow, liveness gates.**
PLAN:141 "Parent patches obey the same ownership check as cards" — ownership only. PX-17 graded "build + target + whole-suite no worse". A wrong patch on a function with thin tests merges (R7g was exactly that, by a human).
Severity: serious. Fix: parent patches go through `finalize_pass` gates identical to cards.

**F-4-5: "Whole-suite no worse" is weak while 563/676 tests are red.**
Measured: 563 failed / 108 passed. "No new failure" constrains 16% of the suite; any change on an unbuilt path is invisible. Applies to regression, escalator fixes, and determinism "repeat seed" on stub builds.
Severity: serious. Fix: gate on the exact failing-id set, not counts; and note the gate's real coverage in every ledger row.

**F-4-6: agy escalator runs as an agent with permissions skipped; the fence is prose.**
`agy_client.py:135 --dangerously-skip-permissions --sandbox`, no cwd set, service `WorkingDirectory=agora`, project path in the prompt. An agentic CLI can read fenced tests, the bible, or the repo regardless of what the prompt "shows". `--sandbox` semantics unverified anywhere in the repo.
Severity: serious. Fix: verify sandbox denies FS; or call model APIs, not the agent CLI, for the seat.

**F-4-7: Auto-merge cherry-picks into Westley's live, dirty checkout and pushes; parallel DONEs collide.**
`build.py:630-641` cherry-pick onto `project` main + `git push`; conflict → "left for manual merge" (`:645`) → human. `git status` shows a dirty tree (`scenes/mockups/*`). A DAG lets two cards on one file (204a3/204b2 both own `om_step_resolve`) finish concurrently from the same base; second cherry-pick conflicts. "Revert on regression" pushes a revert while other worktrees branch off the pre-revert base.
Severity: serious. Fix: merge queue: serialize merges in a bare clone, rebase-test each candidate on current main, push from there; never touch the live checkout.

**F-4-8: Gate cards pass on exit code; skips/xfails count as green.**
`build.py:712-737`: acceptance exit 0 → DONE. Chain-end gate "minus known xfails" (Q9a) is a human-edited list. A worker cannot edit tests, but 4 skipped + 1 xfailed already sit in the suite.
Severity: minor. Fix: gate parses counts; skipped/xfail > baseline → red.
