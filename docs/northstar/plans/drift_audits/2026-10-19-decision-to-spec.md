1. **Commit each workflow script, its args and every gap ruling to `workflows_2026-10-07/` at launch, and fold the rulings into the spec before the launch** (rows 1, 9). This makes the brief hop auditable and stops the spec on main lagging the script.
2. **Make the record clerk grep `plans/` and the register for the topic's earlier decisions when a verdict is recorded. In the same commit it adds a "superseded by" banner to each paragraph and test header that encodes the old behaviour, and a spec paragraph may not set aside an existing bible rule without a register row** (rows 2, 4, 10).
3. **Where a `[W]` quote has a quantifier ("at least half", "never", "every", "at any age"), the test brief must paste it and the test must assert it directly, or the number beside it stays a register row marked "reading, Westley to confirm" and is not shown as closed** (rows 8, 9, 11).
