Drift audit 2026-10-10 e, read-only, on origin/main 38b75486. I read the code and docs and did not run any test suites. The worktree is removed, with no changes and no commits.

**1. Placement contradicts the footprint rule.** Rules R-193-03 and R-168-01 say a placed building clears the self-built pieces under its footprint and refills those around it. The E1e ruling (spec :140, "as the builder drafted") instead refuses placement within 4 cells of any lot. The code does the same (`csrc/economy_place.c:42-46`, return `E1E_OVERLAP`) and clears nothing (grep finds no clearing in `economy_place.c`, `economy_lots.c` or `economy_density.c`). Spec :108 still lists "footprint clearing (R-193-03, R-168-01)" as an E1e deliverable, so it is unbuilt. This is a contradiction. No Westley line allows a refusal in place of clearing.

**2. A solo commander gets a placement panel the bible says does not exist.** R-168-01 says "Given a paired economy player". E-22 line 63 says "a solo commander never does" place buildings, and line 18 says rules run the economy in the core single-commander game. The spec makes `place` an ordinary player command (spec :106) and plans a `PlacementUi` in the tactical view (spec :182, :184). It also names S-168 as a "Seen-reachable" play. Whether paired mode is meant to be faked in solo is an open question, not a ruling. Q-PROG-01 waives open flags, but it does not remove this contradiction. This needs your call.

**3. R-218-06 plus free production gives more than a full force.** R-218-06 and the spec (:134) set the starting force to the whole F and the reinforcement capacity to 0, as a liberty until S-211 exists (`csrc/tactical_support.c:470`). But strongpoint production is still the old structure code and is free: the economy charge in R-218-03 is E2, and spec :140 says so. The player therefore gets F at the start plus free production on top. R-126-04's "a player holding every structure fields at least F" is now loose. No ruling names this interim balance, and no Westley line authorises it.

**4. The E-15 epic is stale on three superseded rules.** E-15 line 37 (R-126-04, 0.20 F split) and line 51 (R-127-03, "never rebuilt") still stand. Their banner says "The rules below are what the game does today", which is now false for both. The 0.20 F test and the "never rebuilt" assertions are gone (TD-VG-E-2 and TD-VG-E-3). R-126-01's "player at least 1" structure is also broken by the R-218-01 slope cap. A ground map with no slopes now gets no structures (TD-VG-E-5).

**5. The doctrine default contradicts a closed Westley answer.** Q-233-01 is closed with his words: "unset (no production) until the player sets it". The sim ships a fresh-world doctrine of 3 (balanced), and every tactical frame shows it (`docs/architecture.md:404, :416`). The deferral is on record as Q-E1-02 (`ambiguity_register.md:499`), so it is acknowledged. But the shipped state contradicts Q-233-01. The spec's naming is also stale: spec :142 says the doctrine setter is "K-e3, in E2", while K-e3 now means the density-field contract (spec :159).

**6. The building roles do not match R-168-05.** The bible lists drop-off points, housing, production and defenses. The validator requires production, house, worker-hut and forward-works (`scripts/specfactory/pack_validate.py:84`). Drop-off and defense roles are absent, and two roles are invented. The manifest `footprint` ([3,3], [2,2]) is ignored, because placement uses a fixed 5x5 (`economy_place.c:8-9`). Nothing records this as a ruling.
