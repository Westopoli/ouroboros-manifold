Reading the tables. Status counts per row use the lint: UNREACH = tested but no static path from om_world_step, om_tactical_step, om_time_jump_run or a pipe handler; ALLOW = same but in reach_allowlist.toml (test hook or accessor); TICK = a static path exists; STATIC/UNREACH? = internal helper (not in the header) reached only through other rows. 'Reachability' says reachable-from-tick, reachable-from-pipe or unreachable. A test is 'direct' when a tests/ file calls the function by ctypes. Pipe verbs and frames: verbs in om_pipe.c main(): step, run_to, snapshot, set_seed, set_feature, inject, objective_complete, place_structure, save, load, mission_start, mission_begin, mission_refuse, mission_end, assign_commander, jump, tactical_step, command (move, attack_move, attack_target, activate_ability, set_layer, ping, place, hold), net_*, terrain_*, lots_dump, space_field_dump, list_saves, quit. Frames: hello, snapshot, delta, tactical, chronicle, mission, debrief, saves, net_*, terrain*. Class letters: P = reachable and observable, O = reachable but unobservable, U = unreachable, N = test fixture only (no mechanism).
