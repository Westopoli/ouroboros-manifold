## Summary

H-063's code landed on main on 2026-11-04 (merge `3faf0044`). Seven gaps keep it from being the stage the plan describes: (1) the reachability REJECT (rule R8) routes over a 20 wu Python grid of the planar rectangles and never reads the engine's walk mask or the engine's 50 wu block rounding; (2) the control fight ("the same fight without the ground") also loses walking (its units fly, because `features.apply` returns False when `features` is empty) and its `layout_path` is the original layout, so the replay draws the walls the control walks through; (3) the replay hardwires `small_flat`, so a slope layout is drawn flat; (4) the page shows the control strip and the three sentences only for rated layouts, its header says "Stage 2 ... not landed", and nothing shows `blocked`; (5) no slope layout in Westley's words exists; (6) docs contradict the code; (7) the replay needs no pipe or C build but `scripts/play.sh` is Linux-only, so he cannot watch on his Mac. This cascade closes (1) to (5) and (7) in seven file-disjoint leaves; the overlord writes the parent-owned docs for (6) in the landing commit.

Pre-flight (2026-11-05, main `634c4eb5`): `git merge-base --is-ancestor 3faf0044 HEAD` true; `pytest tests/skilllab/arena/test_run_reachability.py test_page_control_strip.py test_page.py test_snapshot.py` 68 passed; `scripts/skilllab/arena/features.py` last touched `d30562ff`; `OM_NAVMESH_CELL_SIZE` rounding read at `csrc/tactical_mapgen.c:851-876` (a block covers cells `floor(lo/50)` to `ceil(hi/50) - 1`); no engine call reads block state back (`scripts/skilllab/engine.py` has `block_rect`, no reader); `Engine.terrain_walk_mask(w, layer)` returns one byte per 100 wu terrain cell (`engine.py:442`) and is empty-sized on a world with no generated terrain; catalogue highest id `L-0083`; Godot 4.6.3 runs the replay with `--path`, `OM_FIGHT`, no pipe (`scenes/proto/fight_replay/fight_replay.gd:62-72`); `.claude-swarm.toml` carries this cascade's three settings from this commit. No open `Q-` row touches H-063.

## Inputs / Outputs / Constraints / Out of scope

- Inputs: a layout TOML/JSON from `docs/northstar/research/layer_dynamics/catalogue/`, a seed, `--control-dir`.
- Outputs: fight files (`schema om-fight-2`, additive keys `landscape` and `movement_kind`), control fight files with a twin layout beside them, `results.md` with a `blocked` column, a page, replay frames.
- Constraints: `csrc/` untouched; `om-fight-2` name unchanged (additive optional keys, ruling 5 of H-063, `DEC-fight-file-landscape-2026-11-05`); the fight-file schema is a lab artifact, not a game contract; determinism: same layout, seed and flags give byte-identical fight files.
- Out of scope: sight, facing, arcs as fire cones, height bands, the scan, vantage layouts, any `csrc/` change, a `fight.json` schema version bump, running fights on the Mac, a rewrite of `scripts/play.sh`, abilities.

## Acceptance criteria

Leaf A, `scripts/skilllab/arena/features.py` (engine-backed reachability)
1. `first_unreachable(engine, w, layout, preset, point, sides)` (contract) builds its open-cell grid on 50 wu cells (`NAV_CELL`, the engine's `OM_NAVMESH_CELL_SIZE`). A cell is blocked when `apply` would set its bit: every rectangle of `_engine_boxes(layout)` is rounded out to whole cells (`floor(lo / 50)` to `ceil(hi / 50) - 1` on each axis). When the layout has a slope, a cell is also blocked when the engine's walk mask is 0 at its centre for every layer of the preset (`engine.terrain_walk_mask(w, layer)`, one byte per 100 wu terrain cell, read from a world on which `apply` has run; DRAFT-reach-mask-union, a cell is open if any layer's mask is non-zero). Routing, the "own cell or a neighbour" pass rule and the first-unit naming (`side_a` rows first, then `side_b`) are as today. The function returns None when the layout has neither planar rectangles nor a slope.
   Tests (real engine): (a) the chokepoint fixture with a 60 wu gap (walls' inner edges at y 1970 and 2030, `orders = hold:A`) is rejected naming `side_b unit 0`, and the same fixture with the 200 wu gap passes; today the 60 wu gap passes (20 wu grid) and is shut by the engine's rounding; (b) the fixture with walls touching is rejected naming `side_b unit 0`; (c) a slope fixture (`SLOPE_FIXTURE` below) with one B unit placed on the cliff (x 2000, y 1500, inside the slope columns and outside the ribbon rows) is rejected naming that unit, and the fixture with every B unit at the foot passes.
   `SLOPE_FIXTURE`: landscape `small_tiered`, feature `{kind: slope, x: 2000, y: 2000, length: 600, width: 200, heading: 0.0, from_band: 0, to_band: 1}`, orders `hold:A`, side A eight Vanguards on layer 1 at x 2480 to 2560, side B eight Vanguards on layer 0 at x 1000 to 1080, y 1960 to 2040.

## Scale & Boundary Profile

- **N typical / N peak:** 16 to 112 units a fight typical; 256 a side (512) peak (R4 maximum); frames at most 20 per fight (`snapshot` DRAFT-snapshot-count).
- **Growth claim per hot path:** `features.first_unreachable` is `linear-ish` in cells plus units (a 4000 x 4000 field is 80 x 80 = 6,400 cells at `NAV_CELL` 50); `run.fight` is `linear-ish` in ticks times units (the `still` scan is one pass per sim second); `page.build` is `linear-ish` in fights.
- **Memory posture:** bounded-buffer: frames are at most 20 per fight and kept in memory per fight only.
- **External call budget:** the engine library is built once per process; one world per fight and one throwaway world per reachability check; no network.
