# Look-judge rig (verify lane)

Source plan: `~/.claude/plans/cached-sniffing-pelican.md`. Decision: `DEC-look-judge-rig-2026-11-24`. Tests live in `tests/look/` (Python, pytest) except the Godot piece (`tests/qa/`). All new code goes in new files; `fight_replay.gd` gets one wiring commit last.

## Shared vocabulary

- **Verdict** = `PASS | FAIL | UNSURE`; UNSURE counts as FAIL everywhere. A missing frame, timeout, crash or backend disagreement is FAIL or UNSURE, never PASS.
- **Check kinds**: `state` (code over the fight file), `render` (code over a frame PNG plus its sidecar), `look` (vision model, one crop per call, fresh context), `compare` (code over two traces, feel rules). A `look` check can only add a FAIL to a requirement whose state and render checks passed.
- **Fight file** = schema `om-fight-2` (`docs/northstar/story_reviews/westley/look_2026-11-19/*.fight.json`): `frames[i] = {tick, alive[2], units[{id, side, role, layer, x, y, hp, alive, facing, fired, target}]}`, `seed`, `orders`, `result`, `violations`, `snapshot_every`, `tick_rate`.
- **Look card** (`scripts/look/cards/<id>.toml`): `id`, `requirements = ["R-097-05"]`, `words` (the requirement in Westley's words), `[[checks]]` each with `kind`, `name`, `success` (what meeting it looks like, written before any image is seen), `params` (named `DRAFT-` numbers), `broken_twin` (id of a planted control that must FAIL).
- **Control set** (`scripts/look/controls/`): planted breaks, each a fight file or frame plus sidecar that a given check must FAIL: stacked pair, unit in wall, shot through box, unit drawn off its state position, frozen frame, blank frame. Plus the matching clean twin that must PASS.
- **Verdict table row** (JSON, one per requirement per run): `{req, check, kind, verdict, numbers, crop, frame, tick}`. A run's page = table sorted FAIL/UNSURE first.

## Pieces (each its own files; test writer and builder are different agents)

1. **core** — `scripts/look/card.py` (load/validate cards), `state_checks.py` (checks over a fight file; reuses `scripts/skilllab/invariants_r6.py`; first check: no two same-layer units closer than one radius for more than 3 ticks, R-097-05), `runner.py` (cards + run directory to verdict rows; fail closed), `report.py` (the one page, HTML, FAIL/UNSURE first), cards `overlap.toml` (R-097-05) and `trap.toml`, and the state-level control set. Verification: A1 reports units 82/120 under one radius at tick 1396, matching the trace; the run twice is byte-identical.
2. **backends** — `scripts/look/backends.py`: one interface `judge(crop_png: Path, check: dict) -> {"verdict", "answer", "raw"}`; back ends `ollama` (HTTP `images` field, model name from env `OM_LOOK_OLLAMA_MODEL`, default `qwen3-vl:8b`) and `claude` (headless `claude -p`, one image per call, fresh process). The model answers a named class, a count or coordinates; the module parses it and compares it with the sidecar/truth passed in, never trusting a bare yes. Answer cache keyed by frame hash + prompt hash + back-end id (`.cache/look/`). `scripts/look/calibrate.py`: runs a back end over the control set, reports false-pass count per check and agreement with labelled frames; exit 1 if any false pass (`DRAFT-look-false-pass-max` = 0). Tests use a fake server and a fake `claude` binary, no real model.
3. **render** — Godot: new `scenes/proto/fight_replay/replay_sidecar.gd` writes `frame-<i>.json` beside each `frame-<i>.png` (every unit: id, side, screen x, y, radius px, colour) and, behind env `OM_ID_RENDER=1`, a second flat-colour ID render `frame-<i>.id.png` (each unit one unique flat colour, no effects, no HUD); `fight_replay.gd` gets the one wiring commit. Python: `scripts/look/render_checks.py` samples pixels at sidecar positions, counts per-unit ID-colour pixels (overlap, hidden, wrong layer). Verification: on A1 at frame 96 the two circles' pixels overlap; on a planted twin with the pair moved 40 apart, no overlap. Every Godot run sits under the capped `systemd-run` scope (`scripts/play.sh` shows the pattern).
4. **ledger** — `docs/northstar/story_reviews/westley/approved_scenes.toml` and `scripts/look/ledger.py` (validate, list, `reopen <row>` prints the command, `verify <row>` re-runs and checks the trace hash). One `[[row]]` per approval: `requirements`, `sha`, `scene`, `fight_or_layout`, `seed`, `reopen_command`, `frames`, `words` (verbatim), `date`, `trace_hash`, `source` (file:line or chat). Backfill from `ruled.md`, `verdicts_2026-10.md`, the catalogue `verdicts.md`, and chat transcripts under `~/.claude/projects/-home-westopoli-Projects-ouroboros-manifold/*.jsonl`. A row whose sha or file cannot be recovered goes to `docs/reports/2026-11-24-ledger-unrecovered.md`, never guessed.
5. **compare** — `scripts/look/compare.py`: runs/loads an approved trace and today's trace, computes the measures (per-unit path shape and length ratio; arrival-time spread; formation spread over time; nearest-neighbour spacing distribution; stops, reversals and jitter via `scripts/qa/rts_detectors.py`; time overlapped; shots fired and kill order), checks each against tolerance `DRAFT-feel-<measure>` (values in `scripts/look/tolerances.toml`, all marked DRAFT, Westley's), emits PASS/FAIL rows and a side-by-side page data file. Calibration: approved vs itself gives zero difference; approved vs a planted movement break (units stopped short, the 2026-11-18 give-up bug) FAILs.
