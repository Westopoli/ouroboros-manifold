## Method

Rows: every top-level tracked entry; every subfolder of `docs/`, `docs/northstar/`, `docs/northstar/plans/`, `scenes/`, `scenes/mockups/`, `scripts/`, `tests/`, `docs/research/`; every loose file directly under `docs/`, `docs/northstar/`, `docs/northstar/plans/`, `scripts/`, `scenes/mockups/`, `docs/research/`; plus `.swarm/backups`, and one row for the loose files directly under `tests/`. Files = `git ls-files` count (all of the repo is tracked; `build/`, `graphify-out/`, `.swarm` are committed). Last commit = `git log -1 --format='%as %h' -- <files>`.

"Referenced by", per row, the exact command (patterns file `pat.txt`, one per line, generated by a script outside the repo):

```
git grep -l -F -f pat.txt -- scenes autoload csrc scripts tests Makefile project.godot .claude CLAUDE.md docs/northstar docs/bible
```

Hits inside the entry's own files are dropped; the count is of the remaining hits; the three listed are live referrers first. `pat.txt` holds the basename (with extension) of every file in the entry. Three deviations from the brief, so the column is honest:
- For a folder the bare folder basename is replaced by its repo path with a trailing slash (`docs/legacy/analysis/`), because bare words (`data`, `build`, `push`) match prose everywhere.
- Skipped as too generic: `README.md`, `__init__.py`, `.gdignore`, `.gitignore`, `.gitattributes`, `.editorconfig`, `LICENSE`; `.uid` and `.import` sidecars are not searched for.
- The match is a plain substring, so a folder with many files (or copies of game files, as `build/` and `.swarm/backups` hold) over-reports referrers. A folder row's class is "live" when any one file or its path is referenced; read it as an upper bound and open the folder if it matters.

Class, applied in this order: junk by path (`build`, `.swarm/backups`, `graphify-out`, `saves`, `tuning_output`, `docs/research/graphify-out`); records by path (`docs/bible*`, `story_reviews`, ledger and register files, `plans/push`, `plans/decision_pack_*`, `plans/retro_*`); live when any referrer is in `scenes/`, `autoload/`, `csrc/`, `tests/`, `scripts/specfactory/`, `project.godot`, `Makefile`, `CLAUDE.md`, `docs/northstar/plans/2026-10-07-*`, a `ROADMAP.md`/`PLAN.md`/`README.md` under `docs/northstar`, or `pieces.toml`; also live without a referrer for `csrc`, `autoload`, `scenes`, `tests`, `scripts/specfactory`, `project.godot`, `Makefile`, `CLAUDE.md` (they are the game, the tests and the gate); legacy otherwise. For `simulation/`, the Note lists the module names matched by `git grep -h -E '(from|import) +simulation|simulation/' -- scripts tests`, filtered to names that exist in `simulation/`; names that match only by collision with another word are listed separately.
