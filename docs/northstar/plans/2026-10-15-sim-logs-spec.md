## Rulings needed from Westley before launch

- **W1 the window.** The bible and the reference disagree. E-10 R-073-01 says "this window" three times (Defensive Stand "targeted by an enemy attack this window"; Reconquest "lost by conquest this window"; Multi-Front "two or more factions this window"); the reference never windowed. Storage is a ring either way (oldest overwritten; caps `DRAFT-log-attacks` 4,096, `DRAFT-log-conquests` 1,024, `DRAFT-log-events` 4,096: three to six 50-tick jumps at 400 regions, from the 2026-10-15 sweep's 12,327 attacks and 22,683 events over 25 jumps). The ruling is what readers count: (a) **the bible's window: entries with `tick > window_start`, where `window_start` is the tick at which the previous mission ended or was refused (set in `om_mission_end` and `om_mission_resolve_refusal`); 0 at campaign start, so the first chapter counts everything; saved**. A viewer that drives several jumps with no mission between them widens the window over all of them, which is intended (the pool then reads the whole stretch); the ring may truncate such a stretch after about eight jumps, which is accepted. (b) the reference: every entry the ring holds. (c) a fixed tick count behind the pool-build tick (a number of Westley's). Lean (a): it is the bible's word.
- **W2 the Defensive Stand trigger.** The bible: "targeted by an enemy attack this window" (R-073-01). The reference: an attack on the region by a non-player faction in the attack log (`mission_generator.py:81-96`), resolved attacks only. The C arm (`mission.c:558-561`) reads "any hostile neighbour OR (a conflict set with telegraphs)"; `tests/csim/test_E10_S072_orders_come_from_where_the_world_hurts.py:60-100` pins the hostile-neighbour half. (a) **an attack targets the region when it is logged as resolved in the window or pending as a telegraph against it (an attack in flight is "targeted"); the hostile-neighbour half goes**; the pinning test is a test-defect (`TD-SIM-1`) and is rewritten to log an attack; `test_E10_S072_a2_refresh_telegraph_defensive_stand.py` stays green because its telegraph still triggers. (b) keep the hostile-neighbour half and give an unattacked stand the R-074-01 "otherwise" power (`region.m × 2000`), which sizes it as an insurgency because ALG-57's "committed budget × 300" has no attacker. Lean (a).
- **W3 chain length.** (a) parity: stays 0 (the reference never set it); (b) **filled per jump: an event's `chain_length` is the number of events in the jump sharing its `chain_tag`, from the per-jump chain table (`generational.c:2008-2028`, `chains[].n_events`), read in a second pass after the table is complete so every event sees the jump total; tag 0 (untagged) and an event whose chain fell outside `GEN_JUMP_CHAIN_CAP` count as length 1 (ALG-50 applies its term only when L > 1)**. Lean (b): E-09 R-066-02, R-066-04 and ALG-50 say it.
- **W4 the Containment count.** The bible (R-073-01, the Containment row): "two or more colonizations" by the contained faction this window. The reference: attack conquests with `new_faction_id == region.faction_id` against `CONTAINMENT_EXPANSION_THRESHOLD = 2` (`mission_generator.py:252-271`, `config.py:675`). (a) **the bible: colonisations, logged as conquest kind 5 (`collision.c:172`, `resolve.c:540`), counted alone**; (b) the reference: attack conquests (kinds 0 and 1). The threshold is `DRAFT-containment-expansion` 2 either way. Lean (a). The arm's logic becomes `(count >= DRAFT-containment-expansion) && (revolt_set_count >= OM_MISSION_CONTAINMENT_MIN_REVOLTS || archetype gate as today, mission.c:617-620)`; the test writer quotes the gate.

**State** (`simlog_internal.h`, included by `om_internal.h`):
```c
typedef struct om_log_attack   { int64_t tick; int32_t attacker, target_region; double commit; } om_log_attack;           /* 24 B, no padding */
typedef struct om_log_conquest { int64_t tick; int32_t region, old_faction, new_faction, kind; } om_log_conquest;        /* 24 B; kind below */
typedef struct om_log_event    { int64_t tick; int32_t region, template_id, chain_tag, creates_faction; } om_log_event;  /* 24 B; chain_tag is int32_t as om_fired_event.chain_tag (ouroboros_sim.h:690) */
#define OM_LOG_ATTACK_CAP   4096   /* DRAFT-log-attacks */
#define OM_LOG_CONQUEST_CAP 1024   /* DRAFT-log-conquests */
#define OM_LOG_EVENT_CAP    4096   /* DRAFT-log-events */
#define OM_SIMLOG_MAX_LINEAGES 512 /* the value of generational.c's GEN_MAX_LINEAGES (:181); generational.c gains _Static_assert(GEN_MAX_LINEAGES == OM_SIMLOG_MAX_LINEAGES) */
enum { OM_CONQ_ATTACK = 0, OM_CONQ_MISSION = 1, OM_CONQ_REVOLT = 2, OM_CONQ_REVERSION = 3, OM_CONQ_ABSORPTION = 4, OM_CONQ_COLONISATION = 5 };
typedef struct om_simlog_state {
    uint32_t attack_head, attack_n;     om_log_attack   attacks[OM_LOG_ATTACK_CAP];
    uint32_t conquest_head, conquest_n; om_log_conquest conquests[OM_LOG_CONQUEST_CAP];
    uint32_t event_head, event_n;       om_log_event    events[OM_LOG_EVENT_CAP];
    int64_t  window_start;              /* W1 (a) */
    int32_t  last_mission_region;       /* -1 until a mission ends; set in om_mission_end */
    uint16_t times_run[OM_SIMLOG_MAX_LINEAGES][OM_MISSION_N_ARCHETYPES];   /* by lineage slot; 512 x 10 x 2 B */
} om_simlog_state;   /* 98,304 + 24,576 + 98,304 + 10,240 + 40 = about 231 KB */
```
Ring rule: `head` is the next write slot, `n` saturates at the cap; iteration oldest to newest is `i = (head - n + k) mod cap`. No heap, no hash order, no wall clock.
