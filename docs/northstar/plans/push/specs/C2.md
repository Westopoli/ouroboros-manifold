# C2 — galaxy view over C snapshot + bridge

Manager: M3. Wave 1. `depends_on = ["freeze"]`. Piece id `C2` in
`docs/northstar/plans/push/pieces.toml`. Owns `autoload/c_bridge.gd`
directly and `scenes/galaxy/**`.

Two independent leaves — different files, no shared state, safe in
parallel:
- **leaf-01**: `autoload/c_bridge.gd` — parses a C transport v1 snapshot.
- **leaf-02**: `scenes/galaxy/galaxy_view.tscn` + backing scripts — renders
  it. Reads the snapshot dict directly via `set_snapshot()`; does not
  require `c_bridge.gd` to exist to pass its own fenced test (the test
  degrades to a direct JSON parse when the bridge is missing — see below),
  so no cross-leaf wave dependency is needed even though the production
  wiring later (Godot autoload) has the view consume the bridge's output.

## `autoload/c_bridge.gd` (leaf-01)

Loaded as a **plain script**, never as the project autoload (the fenced
test does `load("res://autoload/c_bridge.gd").new()` directly). Methods,
exact names, from `tests/test_c_bridge.gd`:

- `load_snapshot_file(path: String) -> bool` (or a `{ok: bool, ...}` Dictionary
  whose `ok` key the test also accepts) — reads and parses the JSON file at
  `path`. Returns falsy on a missing `"regions"` key (or any parse
  failure) — **never crashes or throws an unhandled error**. On success,
  stores the parsed snapshot for the other methods to read.
- `regions() -> Array` — the snapshot's `"regions"` array, verbatim or
  lightly normalized (the test only checks `.size()`).
- `owner_of(i: int) -> int` — the `"owner"` field of the region whose
  `"i" == i`.
- `checksum() -> int` — the snapshot's `"checksum"` field.
- `edges() -> Array` — the snapshot's `"edges"` array (test only checks
  `.size()`).

No positions, no names — C5 rule; nothing in the bridge should expose
anything beyond what the wire snapshot already carries.

## `scenes/galaxy/galaxy_view.tscn` + scripts (leaf-02)

Root node contract, exact names, from `tests/test_galaxy_view.gd`:

- `set_snapshot(snapshot: Dictionary) -> void` — takes the raw snapshot
  dict (same shape `c_bridge` reads: `regions`/`edges`/`checksum`, no
  positions). Lays out system positions itself from the current seed
  (mirror `galaxy_gen.gd`'s disc-with-jitter, minimum-spacing approach,
  keyed by region `i` count and index — same seed must reproduce the same
  layout, C5/determinism). Re-calling `set_snapshot` with new owner values
  must be idempotent and re-render (the `conquest-no-recolour` check calls
  it twice with a mutated owner and expects `region_colours` to update on
  the clean path).
- `qa_state() -> Dictionary`, JSON-safe (survives `JSON.stringify`), keys
  the test reads: `system_count` (int, region count), `owners` (Dictionary
  region-i → owner int, one entry per region), `edge_counts` (Dictionary
  keyed by `om_edge_type` int — `0` border/`1` trade/`2` both per
  `csrc/ouroboros_sim.h`'s `om_edge_type` — values sum to total edge
  count), `systems_px` (Dictionary region-i → `[x, y]` window-pixel
  position via the camera's `project`, every entry inside the viewport),
  `region_colours` (Dictionary region-i → `[r,g,b,a]`, must equal
  `owner_colours[owner_of(i)]` exactly — self-consistency, not a fixed
  formula), `owner_colours` (Dictionary owner-id → `[r,g,b,a]`, from
  `faction_palette.gd`'s hue function), `band` (String or similar,
  stringifiable, changes with camera distance), `distance` (float, current
  camera distance), `pick_radius_px` (float > 0 clean), `edges_3d` (bool,
  true clean — filaments are real `Node3D` tube geometry under `World`,
  not a 2D `_draw` overlay), `hash` (int, deterministic per seed — same
  seed twice gives the same hash, a different seed gives a different one).
- `qa_plant(id: String) -> bool` — the six ids below; unknown id (e.g.
  `"nope"`) returns `false`.
- `qa_seed(n: int) -> void` — re-seeds the layout, synchronous.
- `qa_camera(distance: float, target_system_id: int) -> void` — jumps the
  camera to that distance (band changes accordingly per the band
  thresholds below); `target_system_id == -1` means "keep the current
  target, just change distance" (the test calls `qa_camera(80.0, -1)` and
  `qa_camera(20.0, -1)` back to back to compare bands at the same target).

### Bands (mirror `galaxy_view.gd`'s existing numbers unless the fenced
test's own distances force a change — check: the test uses distance 20 vs
80 for `bands-frozen`, wider than the mockup's exact 25/65/75 thresholds,
so 20 and 80 must land in genuinely different bands under whatever
threshold scheme is used; the mockup's Local <25 / Regional 25-75 /
Overview ≥75 boundary already satisfies this)

Overview (far), Regional (mid, default), Local (near, click-to-focus
zooms here) — continuous lerp between, per the mockup's `galaxy_view.gd`
band-blend implementation.

### The six plants (`PLANTS` array, exact ids, verbatim from
`2026-09-22-p1-galaxy-mockup.md` lines ~82-84 and confirmed against
`tests/test_galaxy_view.gd`'s own `PLANTS` constant)

```
PLANTS = ["seed-ignored", "owner-colour-flat", "edges-2d-overlay",
          "pick-radius-zero", "bands-frozen", "conquest-no-recolour"]
```

Fault sites (mirror the mockup's, one line each, gated by
`QaPlants.is_active("<id>")` — but note this is the **production** scene,
not a mockup, so gate through a plain boolean set by `qa_plant`, not
through `scenes/mockups/_shared/qa_plants.gd`, which is mockup-only and
out of this piece's reach): `seed-ignored` forces the seed to a fixed
value regardless of `qa_seed`'s argument; `owner-colour-flat` collapses
every region's colour to one fixed colour; `edges-2d-overlay` flips
`edges_3d` to false (mockup's version draws a 2D overlay instead — here,
minimally, flipping the reported/actual mode is enough since no fenced
check inspects the render tree shape, only the `edges_3d` flag and
`region_colours`/`owners` values); `pick-radius-zero` sets the click pick
radius to 0; `bands-frozen` freezes `band`/rendering at whatever band was
active when the plant activated, ignoring further `qa_camera` distance
changes; `conquest-no-recolour` skips updating `region_colours` when
`set_snapshot` is called again with a changed owner.
