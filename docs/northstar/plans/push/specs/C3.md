## What to build

- `set_snapshot(snapshot: Dictionary) -> void` — same raw C transport v1
  snapshot shape `c_bridge.gd`/`galaxy_view.gd` take. Store it so
  `load_frame` can look up region owners for the `owners` field and
  ref-validity checks (a referenced region id must exist in the
  snapshot's `regions[]`; a referenced faction id must exist in
  `factions[]`).
- `load_frame(frame: Dictionary) -> void` — the rebind entry point,
  independent of `begin_time_jump()`/`queue_entry()`'s legacy
  `{entry_id, base_form, expanded_form, mentions[]}` input. Takes a C
  transport v1 chronicle frame. For each entry: validate every ref (region
  ids against the snapshot's regions, faction ids against its factions);
  if **every** ref on an entry is unresolved, drop the entry entirely
  (`dropped_entries` counts these); otherwise count each individual bad id
  found anywhere (dropped or not) into `unresolved_refs`. Resolve
  `fragment` against `simulation/library/chronicle/fragments.json` (a
  lookup by id — read that file's shape before assuming a key path) to
  build display `text`; when the id is absent from that library, `text`
  is exactly `"[fragment <id>]"`. Calling `load_frame` again must fully
  reset and re-render from scratch — same frame in must give the same
  `hash` out (idempotent).
- `qa_state() -> Dictionary`, JSON-safe: `hash` (int, deterministic over
  the loaded frame's content), `timing_ms` (`{load: float}`), `regen_count`
  (int, increments each `load_frame` call), `entries` (list of
  `{entry_id, fragment_id, text}`, one per **surviving** entry — dropped
  entries excluded, order not specified by the test), `expanded_id`
  (empty string or -1 when nothing is expanded — the test accepts either
  form via `== null or str(before) == "" or int(before) == -1`), `owners`
  (`{region_i: owner}`, exactly the regions referenced by the loaded
  frame's surviving+dropped entries combined — the test only checks size
  and value match, not which regions specifically), `pace`
  (`{word_interval_s: 0.08, fade_s: 0.20}` — bible-mandated constants,
  see the note above, not read from `chronicle_entry.gd`), `dropped_entries`
  (int), `unresolved_refs` (int).
- `qa_plant(id: String) -> bool`, `qa_click_entry(entry_id: int) -> void`
  (opens the expansion headlessly — sets `expanded_id`, no mouse event
  needed since this runs under `--script`), `qa_dismiss() -> void`
  (clears `expanded_id`). `PLANTS := ["entries-dropped", "refs-unresolved"]`
  — new to this piece, not from any mockup brief (the p7 mockup's own
  `PLANTS` cover different, unrelated concerns). Fault sites:
  `refs-unresolved` disables ref-existence checking entirely
  (`unresolved_refs` reads 0 even with a bad ref present); `entries-dropped`
  disables the drop-if-wholly-unresolved rule (`dropped_entries` reads 0,
  the broken entry appears in `entries[]` instead, size 7 not 6). Unknown
  id returns `false`.

`entries[]` deliberately does NOT carry the p7 mockup's printing-progress
fields (`printed_words`/`total_words`/`printed`/`expanded`) — this is data
plumbing (frame → resolved prose/refs), not the print-cadence animation.
Whether to also wire `load_frame` into the existing `queue_entry()`/
printing-animation path for an actual on-screen rebind is a follow-up, not
this piece's fenced acceptance (same split C4 made for its own UI wiring).
