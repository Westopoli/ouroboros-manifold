# E-04 — Events and Chains — end-to-end definition

Stage 3 e2e for E-04. The epic file `docs/bible/epics/E-04-events-and-chains.md` is the source of truth for the stories and the 31 Given/When/Then rules (R-026-01 … R-031-04); this file does not restate them, it adds the test-facing dimensions Stage 5 turns into tests: the full input/output space, edge cases, scale gates, QA watch-fors, and failure evidence. Where a rule changed because a flag was answered, the change is noted here and folded into the epic.

The retained equations are `docs/bible/algorithms.md` ALG-32 … ALG-37. The C rewrite reproduces them to the bit; determinism rules are `docs/northstar/research/c_rewrite.md`.

## Flag resolutions folded (2026-09-14)

- **Q-026-01 (a) — simultaneous same-tick triggers.** When several regions cross thresholds on the same tick, every region's crossing is evaluated against tick-start fields after pending queue resolution. A fired trigger's deltas join that region's per-tick delta sum and apply once, so one region's crossing never hides or triggers another's on the same tick. A region crossing only due to a same-tick event fires on tick t + 1 (R-026-07, ALG-33).
- **Q-027-01 (b) — triangular spawn delays.** Chain spawn delay d is drawn from a triangular distribution clamped to [a, b] with mode (a + b)/2: `clamp(round(triangular(a, b, (a + b)/2)), a, b)` drawn via one uniform RNG draw per `ouroboros_sim.h`, replacing `randint(a, b)` (R-027-01, ALG-35).
- **Q-027-02 (b) — pruned entries logged.** Queued events dropped because their conditions fail at resolution time are written to the tick log as `pruned` records with template, region, tick, chain tag, and the failed condition, for consumption by the chronicle (E-09) (R-027-07, ALG-36).
- **Q-028-01 (a) — coin-flip tie-break.** Two mutually exclusive events with equal probability tie-break by one uniform RNG draw: draw < 0.5 keeps the earlier-queued entry, otherwise the later-queued entry; the loser is re-queued for tick + 1 or tick + 2 (one draw) (R-028-03, ALG-37).
- **Q-031-01 (c) — S-031 pacing thresholds measured from reference sim.** The pacing rates for attacks, conquests/colonizations, faction creation/removal, and chronicle candidate density over 30-tick windows in 5,000-tick runs are measured from the Python reference sim across ten seeds before S-031 tests are written (R-031-01 … R-031-04).

## Actor and surface

No player action reaches this epic directly. Every input is a sim event: the strategic tick loop advances tick n ≥ 1; E-02 supplies region fields (military, economy, tension, population) and floors; E-08 supplies noise offset rolls per time jump; the launch library file supplies 26 authored event templates with their triggers, effects, spawns, and exclusion tags; E-05 supplies external chain spawns (Conquest Unrest from ALG-22, Admin Separatist carrying chain length L from ALG-29). The only surfaces that show this epic's output to a human are E-09 (chronicle fragments reading event and pruned records with chain tags) and E-16 (world view showing field changes, revolt marks, and faction creation); both are their own epics. For QA this is a pure T1 epic: everything is read from the strategic snapshot, the per-tick event log (`events`, `delayed`, `pruned`), the pending queue, trigger state per region, and the T1 trace, with no direct rendering.

## Input space

| Input | Source | Range | Rejection / boundary behavior |
|---|---|---|---|
| Template table | Library file | 26 templates at launch, each with trigger (or spawn only), effects [m, e, t, p] (each integer in [−4, 6]), chain spawns (template, delay [a, b], p ∈ [0, 1], condition C), exclusion tag | Unknown field name, direction not `above`/`below`, delay range with a < 0 or b < a, probability outside [0, 1]: library fails to load (R-030-01) |
| Region fields (military, economy, tension, population) | E-02 region state | [0, 100] float each | not applicable (E-02 clamps enforce bounds; runtime never produces out-of-range) |
| Noise offsets | Rolled per time jump (E-08, ALG-32, R-026-04) | [−10.0, +10.0] uniform float per (region, threshold template) | not applicable (drawn within range; fixed for entire jump) |
| Tick n | Tick loop | integer ≥ 1 | ticks 1..3 grace period primes trigger state without firing (R-026-05, ALG-33) |
| External spawns | ALG-22 conquest, ALG-29 admin revolt (E-05) | template id ("Conquest Unrest", "Admin Separatist"), due tick, probability 1.0, condition none | Unknown template id fails the tick |
| Admin-revolt chain length L | ALG-29 admin revolt (E-05), or the `om_event_queue_external` fixture | integer L ∈ [3, 8] | `om_event_queue_external` returns −1 and queues nothing for an Admin Separatist with L outside [3, 8] (trivial decision, Claude 2026-09-14); E-05 never produces one. |
| Pending queue entries | Save file, runtime chain spawns | `{template, region, due_tick, probability, conditions, chain_tag}`; queue depth ≤ 2,000 entries | A save whose queue holds an unknown template id, a due tick before the current tick, or a probability outside [0, 1] fails to load, as an out-of-range field does in E-02. At runtime a spawn that would exceed the 2,000-entry capacity is dropped and written as a `pruned` record with condition kind NONE (the overflow marker), so the invariant test sees it; nothing is silently lost. |
| Regional revolt cooldown state | Region trigger state / save file | integer tick of last firing, or `tick − last_fired < 12` | not applicable (cooldown suppresses probability roll until tick ≥ last_fired + 12; R-029-03, ALG-34) |
| RNG stream | PRNG contract (`ouroboros_sim.h`) | uniform draws in [0, 1), integer draws | not applicable (deterministic sequence per seed) |

Boundary inputs that must be tested:
- Threshold crossings: field value exactly equal to `T + offset` vs strictly greater/lesser (R-026-01: `above` fires when last tick ≤ T + offset and this tick > T + offset; `below` fires when last tick ≥ T + offset and this tick < T + offset).
- Specific template thresholds: Garrison Collapse (military < 30 + offset), Trade Boom (economy > 55 + offset), Population Crisis (population < 20 + offset), Labor Shortage (population < 40 + offset), Infrastructure Decay (economy < 40 + offset), Military Buildup (military > 50 + offset), Cultural Renaissance (economy > 60 + offset), Famine (economy < 10 + offset), Diplomatic Incident (tension > 35 + offset), Harvest Surplus (population > 50 + offset).
- Spawn conditions at resolution tick: Border Incursion (military < 18), Emergency Levy (economy > 25), Regional Revolt (tension > 40), Prosperity Unrest (tension > 40), Immigration Wave (economy > 30), War Weariness (tension > 30), Famine Relief (economy > 12), Revolt Crushed (military > 35), Revolt Entrenched (tension > 40).
- Grace period boundaries: tick 3 (last tick of grace period, trigger state primed, no firing) vs tick 4 (first active trigger evaluation tick, R-026-05).
- Noise offset boundaries: offset exactly −10.0, 0.0, +10.0 (R-026-04, ALG-32).
- Regional revolt probability roll boundaries: tension exactly 0.0 (p = 0.0, R-029-02); tension exactly 64.0 (p = 0.007 · 0.64^0.8 ≈ 0.004898, R-029-01); tension 100.0 (p = 0.007); cooldown tick t + 11 (suppressed) vs tick t + 12 (active, R-029-03).
- Exclusion tie-break draw: RNG draw strictly < 0.5 (earlier kept) vs ≥ 0.5 (later kept) (R-028-03, ALG-37).
- Admin-revolt chain length: L = 3 (short chain, skips Political Crisis and Popular Support), L = 5 (medium chain, skips Popular Support), L = 8 (long chain, includes all steps) (R-027-05).
- Field clamping floors and ceilings: economy delta pushing below 8.0, tension delta pushing below 12.0, other fields pushing below 0.0, any field pushing above 100.0 (R-026-06, ALG-35).
- Pending queue capacity: queue depth at 2,000 entries (Invariants).

Fresh triggers and due queue entries are evaluated against tick-start fields; per-region deltas sum and apply once with floors and ceilings, and composites recompute after clamping, never before (R-026-06, R-026-07, R-028-01, ALG-35, ALG-36).

## Rules

The 31 rules R-026-01 … R-031-04 live in the epic file and are the authority. Stage 5 writes one failing test per rule, each naming its `R-###-##`. Two dimensions the tests must respect beyond the rule text:

- **Snapshot-versus-live reads.** All pending queue conditions and all fresh threshold trigger crossings for a tick are evaluated against the tick-start fields (R-026-07, ALG-33, ALG-36). No same-tick event execution updates fields while other events or other regions are evaluating crossings or conditions. Deltas from due queued events and fired fresh triggers sum per region, and that combined delta applies once against the tick-start snapshot. A region that crosses a threshold solely because of another event's field delta on tick t evaluates that crossing on tick t + 1, never on tick t. A test that applies deltas sequentially or reads live modified fields mid-tick is a test bug.
- **Order of operations.** Per tick: (1) Pending queue resolution: gather entries with `due == tick` grouped by region; (2) Mutual exclusion pass: per region, evaluate exclusion tags in sorted tag order, keep highest-probability entry (coin flip for ties), re-queue losers to tick + 1 or tick + 2 (ALG-37, R-028-02, R-028-03, R-028-05); (3) Condition check: evaluate remaining entries against tick-start fields; if condition fails, log `pruned` and drop without RNG roll (ALG-36, R-027-02, R-027-07); (4) Probability roll: if condition met, roll `r ≤ p`; if passes, fire, queue spawns with triangular delay clamp, and accumulate field deltas (ALG-35, ALG-36, R-027-01, R-027-03); (5) Fresh trigger evaluation: for all regions against tick-start fields (grace period ticks 1..3 primes breached state without firing); threshold templates fire on rising/falling edge across `T + offset`; regional revolt rolls if not on 12-tick cooldown; fired triggers queue spawns and add deltas to the region's per-tick delta sum (ALG-33, ALG-34, R-026-01, R-026-05, R-026-07, R-029-01, R-029-03); (6) Delta application and composite update: apply each region's summed deltas once with floors (economy 8.0, tension 12.0, others 0.0) and ceiling 100.0, then recompute composites once (ALG-35, ALG-36, R-026-06, R-028-01).

## Edge cases

- **Empty region.** A world with 60 regions including 15 empty-tier regions (all fields 0.0, unowned per E-02 R-012-07). Trigger evaluation skips empty-tier regions entirely (ALG-33 evaluates inhabited regions only): no breached flag is primed, no roll is made, `om_event_breached` reads 0. When colonization (E-05 ALG-24) makes the region inhabited on tick t, its flags are primed on that tick from the colony's starting fields and crossings are evaluated from tick t + 1, so a fresh colony never fires on the tick it appears.
- **Floor.** A region with economy at floor 8.0 and tension at floor 12.0 (R-026-06, ALG-35). On tick 20, "Famine" fires (economy −1, tension +4, population −3) and "Revolt Crushed" resolves on the same tick (economy 0, tension −2, military −1). Summed deltas: economy −1.0, tension +2.0. Economy delta would drop economy to 7.0, but clamps strictly to 8.0; tension rises to 14.0. If tension was at 12.0 and deltas were negative, tension clamps strictly to 12.0 (R-026-06, R-028-01, ALG-35).
- **Max.** A region with military 99.0 and tension 98.0. On tick 15, "Military Buildup" fires (military +2, economy −2, tension +1) and "Emergency Levy" resolves (military +3, economy −2, tension +2). Summed deltas: military +5.0, tension +3.0. Military reaches 104.0 pre-clamp, clamped strictly to ceiling 100.0; tension reaches 101.0, clamped strictly to 100.0 (R-026-06, R-028-01, ALG-35). Spawns queue normally.
- **Tick 1.** Run starts at tick 1 across 60 regions. Ticks 1, 2, and 3 are the grace period (R-026-05, ALG-33). Trigger evaluation runs in priming mode: breached flags are initialized from initial field values against `T + offset`, but zero events fire, zero chain tags are allocated, and the pending queue remains empty (or holds only initial scenario spawns). On tick 4, any field that was already across its threshold at tick 3 does not fire (R-026-02, R-026-05).
- **Concurrent.** A 60-region world where region 10 (economy drops from 42.0 to 38.0 crossing Infrastructure Decay threshold 40.0 with offset 0.0) and region 20 (military drops from 32.0 to 28.0 crossing Garrison Collapse threshold 30.0 with offset 0.0) both cross on tick 50 (R-026-07). Both are evaluated against tick-start fields; both fire on tick 50 regardless of whether region 10 or 20 is processed first. Furthermore, if region 10 also has due queued events ("Border Incursion"), its queued deltas and fresh trigger deltas sum together and apply once without reading intermediate deltas (R-026-07, R-028-01).
- **Mid-save and load.** Run a 60-region world to tick 120 with 45 active queued events across various due ticks and non-zero regional revolt cooldown counters. Save state to disk and reload. The pending queue contents (all fields, due ticks, probabilities, conditions, chain tags), region trigger state (breached flags, noise offsets, cooldown timers), and the sequential chain tag counter `chain_NNNN` must round-trip exactly; trace from tick 121 to 200 after load must be bit-identical to an uninterrupted run through tick 200 (R-027-06, R4 #18).
- **Post-jump.** A 50-tick time jump begins at tick 100 (E-08, ALG-45). At the start of the jump, ALG-32 rolls one uniform noise offset in [−10.0, +10.0] for every (region, threshold template) pair (60 regions × 10 threshold templates = 600 offsets). These offsets persist across all 50 ticks of the jump (R-026-04). Queued events and threshold triggers continue evaluating deterministically; pending queue never exceeds 2,000 entries across 5,000 ticks (Invariants, R4 #19).
- **Pause.** When the simulation pause flag is set at tick 75, the tick loop halts: no queued events are popped or resolved, no probability rolls or condition checks occur, no fresh threshold crossings are evaluated, and zero records are appended to tick logs (R4 #17).

## Scale gates

**Confirmed by Westley, 2026-09-14.** Numbers set here are never loosened by Agora; a miss is escalated, not retuned.

| Gate | Number | Notes |
|---|---|---|
| Trigger evaluation, 60 regions × 26 templates | < 20 µs per tick | on forge; single-threaded C |
| Queue resolution | O(due entries) | grouped by region, processed per tick |

The 2,000-entry queue invariant is the epic's, not a Westley gate; it is tested as a watch-for below. Once Agora can build past 60 regions, add a higher rung at the same per-region budget.

## QA watch-fors

Mostly E-04's own T1 detectors, drawn from the epic's "Ways this could be wrong"; the R4 catalog's applicable general signatures are #17, #18, #19. Each is a T1 trace rule and ships with a positive control (a planted build that violates it must be caught).

| Watch-for | Signature | Tier | R4 |
|---|---|---|---|
| Persistent threshold firing | For any (region, template), identical threshold template appears in `events` log on consecutive ticks t and t + 1 while field is not returning across `T + offset` between them (R-026-02) | T1 | — |
| Noise offset churn or shared personality | Noise offset for any (region, template) in state differs between tick t and t + 1 within the same time jump; or all 60 regions share identical offset values for a template at jump start (ALG-32, R-026-04) | T1 | — |
| Grace period omission | Any record in `events` tick log with `tick <= 3` (R-026-05, ALG-33); or any threshold trigger firing on tick 4 without a field delta occurring between tick 3 and tick 4 | T1 | — |
| Premature condition evaluation | Queued event with condition C fails to fire at `due == tick` even though tick-start field satisfies C; or event fires at `due == tick` when tick-start field violates C because C was satisfied at spawn tick t_spawn (R-027-02, ALG-36) | T1 | — |
| Sequential same-tick queue application | In a region with multiple due events on tick t, second event's delta or condition evaluation uses field value ≠ tick-start field; or per-region net field change ≠ clamped sum of individual deltas applied once against tick-start fields (R-028-01, ALG-36) | T1 | — |
| Live field cross-region trigger pollution | In a multi-region crossing test on tick t, region B's trigger evaluation outcome differs when region evaluation order is reversed (A then B vs B then A); or region B evaluates a crossing on tick t that only occurred due to region A's delta on tick t (R-026-07, ALG-33) | T1 | — |
| Exclusion loser cancellation | Mutual exclusion conflict between due events on tick t does not produce a corresponding `delayed` record in tick log with new `due_tick ∈ [t + 1, t + 2]`; or loser entry disappears from pending queue without appearing in `events` or `pruned` log (R-028-02, R-028-03, ALG-37) | T1 | — |
| RNG consumption on failed condition | PRNG state or draw count advances on tick t for a queued entry whose condition C evaluates to false against tick-start fields (R-027-02, ALG-36); trace checksum diverges from reference run | T1 | — |
| Chain tag reuse after load | Fired event after save/reload receives a chain tag `chain_NNNN` matching an existing chain tag generated before the save (R-027-06) | T1 | — |
| Field clamp violation | Any region field in state or snapshot < 8.0 for economy, < 12.0 for tension, < 0.0 for others, or > 100.0 following event resolution on tick t (R-026-06, ALG-35) | T1 | — |
| Pending queue runaway | Pending queue size in state > 2,000 entries on any tick (Invariants) | T1 | — |
| Save and load drift | Trace of `events`, `pruned`, `delayed`, pending queue, and region fields after load differs from uninterrupted trace at the same tick | T1 | 18 |
| Rewind divergence beyond design | Post-rewind event trace does not match expected deterministic playback or fresh stochastic draw sequence per design rule | T1 | 19 |
| Pause desync | Any `events`, `delayed`, or `pruned` record written, or any pending queue delta, while pause flag is active | T1 | 17 |

## Failure evidence

On any watch-for trip, capture: the world seed; the tick window (the failing tick ± 5); the full tick log (`events`, `delayed`, `pruned`) for the region(s) involved across that window; the pending queue contents before and after resolution on the failing tick; pre-tick and post-tick region field values and composite scores; the region's trigger state (breached flags, noise offsets, revolt cooldown timer); the next sequential chain tag id; for save/load or rewind divergence, both traces aligned by tick; for cross-platform desync, the divergent event records and PRNG draw index at the first mismatch. No screenshot is needed (pure T1).
