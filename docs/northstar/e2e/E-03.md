# E-03 — World Generation and Topology — end-to-end definition

Stage 3 e2e for E-03. The epic file `docs/bible/epics/E-03-world-generation.md` is the source of truth for the five stories and their 28 Given/When/Then rules (R-021-01 … R-025-04); this file does not restate them, it adds the test-facing dimensions Stage 5 turns into tests: the full input/output space, edge cases, scale gates, QA watch-fors, and failure evidence. Where a rule changed because a flag was answered, the change is noted here and folded into the epic.

The retained equations are `docs/bible/algorithms.md` ALG-30 (starting-field derivation) and ALG-31 (topology). The C rewrite reproduces them to the bit; determinism rules are `docs/northstar/research/c_rewrite.md`. World generation runs once per campaign; every downstream sim epic reads the graph it produces, so a generation bug is silent until it desyncs a whole campaign.

## Flag resolutions folded (2026-09-14 / 2026-09-15)

- **Q-021-03 (b) — every faction rolls a template.** All 15 factions independently roll one of the three named templates with equal weight (the player's optional preference reweights their own roll only). There is no "player templated, NPCs fixed" split. R-021-03 rewritten in the epic.
- **Q-022-02 (b) — per-archetype home ranges.** A home region's military and economy are rolled from the faction archetype's own range (Conqueror/Fortifier/Opportunist, numbers in R-022-05), not the general R-022-02 clamp target. Frontier regions stay archetype-independent. Tension and population keep the general ranges.
- **Q-021-04 (b) — templates keep their own region counts.** Isolated = 3 regions, Twin Colony = 4–6, Archipelago = 4, per faction. The old fixed "exactly two regions per faction" invariant is deleted; the two-region assumption is gone from R-021-05, R-021-06's corridor rule, and R-022's range application. A faction now owns a variable region count at tick 0.
- **Q-021-05 (a) — galaxy region-count range [60, 110].** Now that a faction needs 3–6 regions instead of 2, the old [40, 60] total no longer fits. Range = [60, 110]. The Scale gate is re-timed at **110** regions (the new max), not 60 (which is now near the minimum). R-021-01 and the Scale requirements section updated in the epic.

## Actor and surface

Almost no player action reaches this epic: the one player input is an **optional template preference set before generation** (R-021-04), which reweights only the player faction's own template roll and never locks it. Everything else is seed-driven. Generation is a one-shot sim event at campaign start; it consumes the RNG in a fixed order and emits the world graph into the strategic snapshot. The only surface that shows this epic's output to a human is **E-16** (the galaxy view draws regions as nodes and edges as filaments), which is its own epic. For QA this is a pure **T1** epic: the graph, adjacency, edge types, owners, starting fields, and template rolls are all read from the strategic snapshot, the save file, and the T1 generation trace, with no rendering.

## Input space

| Input | Source | Range | Rejection / boundary behavior |
|---|---|---|---|
| Seed | Campaign start | any 64-bit integer | none — every seed generates a valid world |
| Region count range | Config | [60, 110] (Q-021-05) | a count below the sum of every rolled faction's template size + 1 corridor region fails generation (see edge case "count too small") |
| Faction count | Config | 15 at launch | < 2 fails generation |
| Template weights | Config | equal (⅓ each) per NPC faction; player faction reweighted by preference | a preference outside {Isolated, Twin Colony, Archipelago, none} fails generation |
| Player template preference | Player, pre-generation | one of the three templates, or none | raises that template's weight in the player roll only; never locks; never touches an NPC roll (R-021-04) |
| Player preference weight | Config (`WORLD_PLAYER_PREFERENCE_WEIGHT`, Q-021-06) | [0, 1], default 0.50 | preferred template's probability in the player roll; the other two split the remainder; no effect without a preference (`om_gen_set_preference_weight`) |
| Extra edge ratio | Config | 0.12 | < 0 fails generation |
| Extra-edge step enable | Fixture only (`om_gen_set_extra_edges_enabled`) | on (default) / off | off skips the whole extra-edge step for isolation tests of placement (R-021-05) and empty attachment (R-021-07); ratio cannot reach zero (floor of 1) so this is the only clean isolation |
| Population / jitter ranges | Config | home [55,75], frontier [25,50], jitter [−5,5] (ALG-30) | ranges that could push a field outside [0,100] fail generation |
| Per-archetype home ranges | Config (R-022-05) | Conqueror mil 50–65/eco 40–55; Fortifier 40–50/50–65; Opportunist 45–55/45–55 | ranges outside [0,100] fail generation |

Boundary inputs that must be tested: region count exactly 60 (minimum) and exactly 110 (maximum); a region count that exactly equals the minimum feasible total (every faction rolls its smallest template + corridors); a region count one below that (must fail generation, not silently under-fill); a Twin Colony rolling 1 vs 2 frontiers per home (the 4/5/6-region spread); the player preference set vs. none.

## Output space

| Output | Where observed | Tier |
|---|---|---|
| Region list: id, tier (home/frontier/empty), owner, four fields, two phase offsets | strategic snapshot `regions`; save file | T1 |
| Adjacency lists | strategic snapshot `adjacency`; save file | T1 |
| Edge types (`border`, `trade`, `both`) per edge, symmetric | strategic snapshot `edge_types` | T1 |
| Faction list: archetype, rolled template, starting tech | strategic snapshot `factions`; save file | T1 |
| Generation report: seed, N, edge count, per-faction template roll, buffer-check result | T1 generation trace | T1 |
| Galaxy drawn as nodes + typed filaments | E-16 galaxy view | T2 (E-16) |

Empty regions carry **no fields and no owner** (all four fields absent/zero, tier empty) until colonized (E-05). A test that reads a field off an empty region is reading a value that must not exist.

## Rules

The 28 rules R-021-01 … R-025-04 live in the epic file and are the authority. Stage 5 writes at least one failing test per rule, each naming its `R-###-##`. Dimensions the tests must respect beyond the rule text:

- **RNG draw order is the determinism contract (ALG-30, ALG-31).** The stream is consumed in exactly this generation-wide order: (1) region count — one draw; (2) the 15 **template rolls, batched** — one weighted draw per faction in faction order, *before any placement*, so the feasibility gate can sum every rolled template's size first; (3) feasibility check — no draw; (4) per-faction **placement**, in faction order — for each faction, its Twin Colony per-home frontier-count draws (1 or 2, when Twin Colony), then each of its regions' field draws in the ALG-30 slot order `population, economy slot, military slot, tension jitter, economy phase, tension phase` (the economy/military slots are the archetype-range draw for an archetype home, else the ratio jitter — the same slot count either way, so determinism is not disturbed; R-022-04); (5) corridors, faction order; (6) empty attachment — each empty with up to 20 re-rolls; (7) extra edges; (8) edge-type assignment — no draw; then one final reseed. A **template roll** uses cumulative buckets in `om_template` enum order — Isolated `[0, w₀)`, Twin Colony `[w₀, w₀+w₁)`, Archipelago `[w₀+w₁, 1)`, half-open — weights equal (⅓ each) except the player faction's own roll when a preference is set (the preferred gets `WORLD_PLAYER_PREFERENCE_WEIGHT`, default 0.50; the other two split the remainder). A test that asserts a value without pinning where in this sequence the draw happened is asserting against an accident. R-021-10 is the umbrella determinism rule: same seed → identical template rolls, region ids, adjacency, edge types, and starting fields.
- **Template placement is a shape, not just a count.** R-021-05 fixes the adjacency inside a template: Isolated's two frontiers both touch the home; Twin Colony's two homes touch each other and each frontier touches its own home; Archipelago must place **at least one** frontier reachable only through a chain of frontiers (not adjacent to the home or to another frontier directly). A generator that produces the right region *count* but the wrong internal adjacency passes a count check and fails the shape — both must be tested.
- **Budget is fixed before template rolls are consumed.** The total region count is drawn first (R-021-01); the sum of rolled template sizes plus corridor empties must fit inside it, with the remainder attached as empties (R-021-07). A generator that lets a late faction's roll change the already-fixed budget silently over- or under-fills (a "Ways this could be wrong" item).
- **Connectivity is a whole-graph invariant, checked after every edge is placed** (R-021-09): every region reachable from every other. The corridor chain (R-021-06) is what guarantees it before extra edges; extra edges (R-021-08) and empty attachment (R-021-07) must never be able to break it.
- **Edge type default is `border`, never `both`.** Only a same-faction edge is `both`; every edge touching an empty region is `border` (R-023-01). An empty must never read as a trade neighbor.

## Edge cases

- **Region count exactly 60 / exactly 110.** Both generate a valid, fully-connected world. 110 is the scale-gate case.
- **Count too small.** A region count below (sum of rolled template sizes + one corridor empty per faction) fails generation cleanly — it does not silently drop a faction or shrink a template. Test the exact boundary and one below it.
- **All 15 factions roll the same template.** All Isolated (minimum inhabited ≈ 45) and all Twin Colony maxed (≈ 90) are the extremes of the inhabited-region total; both must fit the [60,110] range and stay connected.
- **Twin Colony frontier spread.** Each of the two homes independently rolls 1 or 2 frontiers, so a Twin Colony faction owns 4, 5, or 6 regions. Test all three; the second home must roll its fields from the home range, not the frontier range (a named "Ways this could be wrong").
- **Archipelago sparse frontier.** At least one frontier is reached only through a chain of frontiers. A generator that wires all frontiers directly to the home produces an Isolated-with-an-extra-region and must be caught.
- **Player buffer under a tight map.** At the minimum region count with the player boxed between NPCs, R-025 (no player-home/inhabited adjacency, a shortest path through ≥ 1 empty, extra-edge rejection R-025-04) must still hold; if it cannot, generation fails rather than spawning the player on a doorstep. NPC-to-NPC adjacency is allowed and must **not** be rejected.
- **Extra-edge re-roll exhaustion.** R-021-08 attempts `max(1, floor(0.12·N))` extra edges with at most 10× that many draws; R-025-04 rejects any draw that would touch the player's regions and a foreign faction's. If the draw budget is exhausted, fewer extra edges is acceptable; a player-touching extra edge is never acceptable.
- **Empty attachment re-roll.** R-021-07 re-rolls up to 20 times to avoid attaching an empty to a home region; after 20, it attaches to whatever connected region it drew (connectivity wins over the home-avoidance preference).
- **Same seed twice.** Byte-identical graph including template rolls (R-021-10). Cross-platform: same seed on Linux/Windows/macOS is byte-identical (float summation and RNG order).
- **Player preference vs. none.** With a preference, only the player roll shifts weight; the 14 NPC rolls must be bit-identical to the no-preference run at the same seed (the preference consumes no extra NPC RNG).

## Scale gates

**Confirmed by Westley 2026-09-15** (re-timed from the original 60-region figure after Q-021-05 widened the range to [60,110]). Numbers set here are never loosened by Agora; a miss is escalated, not retuned.

| Gate | Number | Notes |
|---|---|---|
| Generation time, 110 regions | < 5 ms, full world from a seed | on forge; single-threaded C; 110 = the range max |
| Complexity | O(N + E) | no O(N²) connectivity scan or extra-edge search; N regions, E edges |
| Connectivity check | O(N + E) | one traversal, not a per-region reachability loop |

Once Agora can build and time this, the 60-region figure is retired; 110 is the confirmed gate. A generator that is O(N²) in the extra-edge or connectivity step will pass at 60 and miss at 110 — the reason the gate moved.

## QA watch-fors

E-03's own T1 detectors, drawn from the epic's "Ways this could be wrong." Each is a T1 trace/graph rule and ships with a positive control (a planted build that violates it must be caught).

| Watch-for | Signature | Tier |
|---|---|---|
| RNG order desync | same seed yields a different galaxy across runs or platforms (draw order or float summation) | T1 |
| Home-to-foreign extra edge | any extra edge (R-021-08) between the player's region and an NPC region, or between two home regions | T1 |
| Disconnected faction | any region unreachable from any other after generation (corridor chain failed under a small empty count) | T1 |
| Empty as trade neighbor | an edge touching an empty region typed `both`/`trade` instead of `border` | T1 |
| Frontier from home range | a frontier region's population outside [25,50], or its fields rolled from the home/archetype range | T1 |
| Per-region reseed | factions share phase offsets because the RNG was reseeded per region instead of streamed | T1 |
| Twin Colony second home wrong range | the second home's fields rolled from the frontier population range | T1 |
| Archipelago not sparse | all Archipelago frontiers adjacent to the home (no chain-only frontier) | T1 |
| Budget drift | a faction's template roll changes the region-count budget after the total was fixed (over/under-fill) | T1 |
| Player doorstep | player inhabited/home region adjacent to any NPC's, or shortest player→NPC path with no empty on it | T1 |
| Region count out of range | N < 60 or N > 110, or generation succeeds below the minimum feasible total | T1 |
| Archetype home range miss | a home region's military/economy outside its archetype's R-022-05 range | T1 |
| Edge asymmetry | an edge read from its two endpoints reports two different types (R-023-04) | T1 |

## Failure evidence

On any watch-for trip, capture: the world seed; N and the edge count; the full per-faction template-roll list from the generation trace; for a connectivity miss, the set of unreachable region ids and the adjacency list; for a determinism/cross-platform miss, both divergent outputs aligned (the first region id or edge that differs, and for cross-platform the two RNG-draw logs at the first divergence); for a buffer miss, the offending region pair and the shortest path between them; for a field-range miss, the region id, its tier, its faction archetype, and the drawn value with the range it violated. No screenshot is needed (pure T1; the visual is E-16's concern).
