## Actor and surface

No player action reaches this epic. Every input is a sim event: the strategic tick loop drives drift once per region per tick; world generation seeds the fields, tiers, and phase offsets; E-05 supplies ownership, faction modifiers, and stances; E-04 supplies event and conquest field changes; E-10 missions change fields through the outcome resolver. The only surfaces that show this epic's output to a human are E-16 (world view faction panel and hover tooltip) and E-09 (chronicle fragments); both are their own epics. For QA this is a pure T1 epic: everything is read from the strategic snapshot, the per-tick drift log, and the 10-tick checksum, with no rendering.

## Input space

| Input | Source | Range | Rejection / boundary behavior |
|---|---|---|---|
| military, economy, tension, population | Region state | [0, 100] float each | Out-of-range at load is a save-file error; runtime drift can never produce out-of-range (clamps enforce it) |
| tier | Region | home, frontier, empty | Any other value fails world load; empty never drifts |
| tick n | Tick loop | integer ≥ 1 | n = 1 takes the previous oscillator value as 0 (R-018-02) |
| phase offsets φ_econ, φ_tension | World generation | [0, 2π) each, drawn at generation | fixed for the region's life; not re-drawn |
| faction modifier | Faction (E-05) | per-field float; launch: conqueror military +0.05·headroom | unknown field name ignored |
| neighbor economy, edge type, stance | World, diplomacy | economy raw (not de-oscillated); edge ∈ trade/border/both; stance per E-06 | empty-tier neighbor contributes nothing (R-015-04); non-friendly stance contributes nothing |
| change source | caller | drift, friction, event, conquest | selects the floor rule: drift/friction/event floor economy at 8.0, conquest may go to 0 (R-019-01, R-019-02) |

Boundary inputs that must be tested: economy exactly 20.0 (recruitment threshold, strictly greater, R-013-04); economy exactly 11.0 and 15.0 (subsistence and growth thresholds, R-016-04, R-017-03); economy exactly at capacity (overcapacity 0, R-014-03); military ≥ 90 (recruitment 0, R-013-05); population 100 (growth 0, R-017-04); tick 1 (oscillator seed, R-018-02).

## Output space

| Output | Where observed | Tier |
|---|---|---|
| Four fields + stability, capacity (2 dp) | region entry of strategic snapshot and delta; save file | T1 |
| Per-term drift deltas (decay, recruit, adjacency, oscillator, pressures) | tick log `drift` entry per region | T1 |
| Field checksum of all fields + composites | T1 trace every 10 ticks | T1 |
| Region condition to the player | E-16 faction panel + hover tooltip; E-09 chronicle fragments | T2 (their epics) |

Composites are recomputed after every field change and after the clamp, never before (R-012-01, and "Ways this could be wrong").

## Rules

The 31 rules R-012-01 … R-020-03 live in the epic file and are the authority. Stage 5 writes one failing test per rule, each naming its `R-###-##`. Two dimensions the tests must respect beyond the rule text:

- **De-oscillation.** Every cross-field coupling term reads the field minus its previous oscillator value (the trend), never the raw field; only the oscillator delta is added to the field (R-018-03, invariant). A test that feeds a raw field where the trend is expected is a test bug.
- **Order of operations.** Per tick, per region: compute all drift terms from trend values → add oscillator delta → clamp fields to [0,100] (economy floor 8.0 unless conquest) → recompute composites. A rule verified against a different order is verifying the wrong thing.

## Edge cases

- **Empty region.** All four fields 0, composites 0, drift never runs (R-012-07). Test an empty region adjacent to a booming one: it still contributes nothing and receives nothing.
- **Floor.** Economy pinned at 8.0 keeps hurting: subsistence still raises tension and lowers population (R-019-03); drift never lifts it off the floor unaided; only conquest breaks below 8.0 (R-019-02).
- **Max.** Military ≥ 90 recruits 0; population 100 grows 0; fields at 100 never exceed it.
- **Tick 1.** Previous oscillator value is 0; no undefined read.
- **Concurrent.** All regions drift within one tick from the same pre-tick snapshot; a region's drift never reads another region's post-drift value in the same tick (adjacency reads the neighbor's raw economy as of tick start).
- **Mid-save / load.** Fields and phase offsets round-trip exactly; a trace after load is byte-identical to the trace that would have continued without saving (R4 #18).
- **Post-rewind / time jump.** After a time jump (E-08) the fields continue drifting deterministically from the jumped state; rewind reproduces per its design rule (R4 #19). Not a stochastic-outcome epic itself, but its trace must match across a save/rewind boundary.
- **Pause.** Strategic drift does not advance while the sim is paused; zero field delta under a pause flag (R4 #17).

## Scale gates

**Confirmed by Westley 2026-09-14.** Numbers set here are never loosened by Agora; a miss is escalated, not retuned.

| Gate | Number | Notes |
|---|---|---|
| Drift time, 60 regions | < 50 µs per tick, all regions total | on forge; single-threaded C |
| Bulk run, 60 regions | 5,000 ticks of drift alone < 0.5 s | no events, no factions |
| Memory per region | < 256 bytes | fields, composites, phase offsets, scratch |

## QA watch-fors

Mostly E-02's own T1 detectors, drawn from the epic's "Ways this could be wrong"; the R4 catalog's applicable general signatures are #17, #18, #19. Each is a T1 trace rule and ships with a positive control (a planted build that violates it must be caught).

| Watch-for | Signature | Tier | R4 |
|---|---|---|---|
| Clamp violation | any field outside [0,100], or economy < 8.0 from a non-conquest source | T1 | — |
| Oscillator drift | net oscillator contribution over any 15-tick window ≠ 0 within 1e-6 (R-018-04); or field drifts upward by the amplitude (oscillator added as a level) | T1 | — |
| Raw-vs-trend read | a coupling term computed from the raw oscillated field instead of the trend | T1 | — |
| Empty-region drift | any drift delta on an empty-tier region | T1 | — |
| Threshold direction | a boundary case decided with ≥ where the source uses > (economy 20.0, 11.0, 15.0) | T1 | — |
| Composite-before-clamp | stability/capacity computed from pre-clamp fields | T1 | — |
| Cross-platform desync | 10-tick checksums differ across Linux/Windows/macOS from one seed (float summation order) | T1 | — |
| Save/load drift | trace after load differs from trace before save at the same tick | T1 | #18 |
| Rewind divergence | post-rewind trace does not match the design rule | T1 | #19 |
| Pause desync | field delta while paused | T1 | #17 |

## Failure evidence

On any watch-for trip, capture: the world seed; the tick window (the failing tick ± 5); the full `drift` log entries for the region(s) involved across that window; the region's pre-tick and post-tick field + composite values; for a cross-platform miss, the two divergent checksums and the tick they first differ; for save/load or rewind, both traces aligned by tick. No screenshot is needed (pure T1).
