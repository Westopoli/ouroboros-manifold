# E-05 — Faction Agents and Conflict — end-to-end definition

Stage 3 e2e for E-05. The epic file `docs/bible/epics/E-05-faction-agents-and-conflict.md` is the source of truth for the stories and the 58 Given/When/Then rules (R-032-01 … R-041-05); this file does not restate them, it adds the test-facing dimensions Stage 5 turns into tests: the full input/output space, edge cases, scale gates, QA watch-fors, and failure evidence. Where a rule changed because a flag was answered, the change is noted here and folded into the epic.

The retained equations are `docs/bible/algorithms.md` ALG-11 … ALG-25 and ALG-29. The C rewrite reproduces them to the bit; determinism rules are `docs/northstar/research/c_rewrite.md`.

## Flag resolutions folded (2026-09-14)

- **Q-035-01 (a) — build recent-damage boost.** The Opportunist's recent-damage boost (×1.5 over a 150-tick window) was authored in config and the bible but never wired in Python. Built in C: damage history tracks per-region military and economy lost to attacks over the last 150 ticks; boost = 1 + (loss / 100) · 1.5. S-034 gains this active mechanic.
- **Q-036-01 — 3-tick telegraph window.** Telegraphed attacks declare on tick t and resolve on tick t + 3 (updating `TELEGRAPH_PREP_TICKS` from 1 to 3) across all archetypes, giving NPC defenders time to see and react with reinforce commands. R-036-03 and ALG-15 update resolution to tick t + 3.
- **Q-037-01 (b) — attacker regions untouched.** Code is the design: the attacker's regions are never touched during combat resolution; a repelled attack costs the defender 10% of effective attack in military and 2.0 tension. Bible claim about attacker home tension is deleted. R-037-08 confirmed.
- **Q-040-01 (b) — variable admin revolt chain.** Admin revolt chains run 3 to 8 ticks with short, medium, and long variants rolled at ignition rather than a fixed 5-tick chain. Fold decision by Claude (the answer did not state the distribution): one integer draw L uniform in [3, 8] at the roll; L in [3, 4] short, [5, 6] medium, [7, 8] long; surplus ticks beyond one per step go to the earliest gaps. R-040-03 and E-04 R-027-05 carry it; Westley may override the distribution.
- **Q-041-01 (b) — border edges only.** Border friction applies flat 0.15 tension and 0.05 economy per hostile neighbor across border edges only (including `both`), not trade-only edges. Live Python code counted all edge types; the C rewrite filters by border edge per the bible's typed-graph section. R-041-02 updated accordingly.

## Actor and surface

No player action reaches this epic in single-player; the player's civilization runs the same autonomous agent (vision_v2: the civilization has its own plans, cautious by design). In multiplayer, human players' factions run the same agent. Every input is a sim event driven by the strategic tick loop:
- Tick step 3a: frozen snapshot of all regions before any mutation this tick (from E-02);
- Tick step 3b: budget accumulation from owned regions (ALG-17);
- Tick step 3c: pending telegraphed attacks declared 3 ticks ago resolve (ALG-20..22);
- Tick step 3d: all factions evaluate neighbors and decide intents (ALG-11..16: scoring, viability, mode selection);
- Tick step 3e: reactive reinforce against newly declared telegraphs (ALG-18);
- Tick step 3f: immediate intents resolve (ALG-19..24), multi-faction collisions grouped and resolved first (ALG-23);
- Tick step 4: border friction across border edges with hostile neighbors (ALG-25);
- Tick step 4.1: admin revolt rolls per owned region for factions with > 4 regions (ALG-29).

Inputs also arrive from E-02 (fields, floors, composites), E-03 (graph topology, adjacency, edge types, starting archetypes, region ownership), E-04 (events: Conquest Unrest queuing, admin chain handling), E-06 (diplomacy stances, tech multipliers), and E-07 (civilizational lifecycle: breakaway creation, zombie cleanup, latent loyalty).

The only surfaces that show this epic's output to a human are E-16 (world view map border and ownership changes, faction data panel), E-09 (chronicle fragments recording wars and conquests), and E-10 (missions spawned by conflict); all are their own epics. For QA this is a pure T1 epic: every intent, candidate score, battle calculation, collision, conquest, garrison, friction application, and admin revolt roll is observable in the strategic snapshot, the tick log (`faction_actions`, `intent_resolver`, `border_friction`, `admin_revolt`), and the deterministic 10-tick checksum trace, with no rendering.

Boundary inputs that must be tested:
- Region economy exactly 8.0 (maintenance cost baseline, contribution 0, R-033-02);
- Region economy < 8.0 (conquest disruption, R-038-01);
- Candidate minimum attack value exactly 0.05 (strictly greater or equal to 0.05 is viable, R-034-04);
- Action score threshold exactly 0.05 (scores < 0.05 result in accumulate, R-035-07);
- Budget pressure ratio exactly 0.8 (ratio > 0.8 scales confidence, ratio ≤ 0.8 leaves confidence unchanged, R-035-03, R-035-04);
- Viability net force exactly equal to effective confidence (strictly greater net > effective_confidence required, R-035-01);
- Target military for telegraph preference: m_target exactly 30 and 60 (penalty −0.2 if < 30, bonus +0.2 if > 60, R-036-01, R-036-02);
- Reactive reinforce commit exactly 1.0 (strictly less than 1.0 commits nothing, R-036-05);
- Reactive reinforce probability cap (defend_weight / 1.5 ≥ 1.0, R-036-05);
- Reinforce military cap at tier cap (home 100.0, frontier 60.0, headroom 0, ALG-19);
- Battle outcome breakthrough threshold: net exactly 15.0 (contested if ≤ 15.0, breakthrough if > 15.0, R-037-01, R-037-02);
- Battle outcome repelled threshold: net exactly 0.0 (repelled if ≤ 0, contested if > 0, R-037-03);
- Breakthrough tension delta cap: net ≥ 60.0 (tension delta capped at +30.0, R-037-04);
- Conquest military threshold: post-damage military exactly 5.0 (conquest if strictly < 5.0 and not repelled, R-038-01, R-038-02);
- Repelled battle with defender military < 5.0 (no conquest occurs, R-038-03);
- Entrenchment ramp boundaries: tick − held_since = 0 (entrenchment 1.0) and tick − held_since ≥ 100 (entrenchment 2.0, R-038-05);
- Collision narrow margin threshold: margin exactly 0.6 (full colony starter military if ≥ 0.6, penalty if < 0.6, R-039-04);
- Admin revolt territory inflection point: territory count exactly 4 (excess = 0, chance 0.001; count 5 has excess 1, R-040-01, R-040-02);
- Border friction economy floor: economy at 8.0 with hostile border neighbors (tension increases by +0.15 per neighbor, economy clamped at 8.0, R-041-04);
- Border friction edge filter: hostile neighbor across trade-only edge produces 0 friction (R-041-02, Q-041-01).

## Rules

The 58 rules R-032-01 … R-041-05 live in the epic file and are the authority. Stage 5 writes one failing test per rule, each naming its `R-###-##`. Key dimensions tests must respect beyond the rule text:

- **Snapshot-versus-live reads (tick step 3a isolation).** Every faction agent decision (candidate scoring, budget pressure, viability, intent selection) and reactive reinforce must evaluate exclusively against the frozen pre-tick snapshot taken at step 3a. Decisions must never read live fields modified earlier in the same tick. Decision order among factions must never leak into outcomes.
- **Strict tick sequence within steps 3 and 4.** Each tick must follow the exact order: (3a) freeze snapshot → (3b) budget accumulation for all factions (ALG-17) → (3c) resolve pending telegraphed attacks due this tick (ALG-20..22) → (3d) decide intents for all factions (ALG-11..16) → (3e) reactive reinforce against newly declared telegraphs (ALG-18) → (3f) resolve immediate intents and grouped collisions (ALG-19..24) → (4) apply border friction across border edges (ALG-25) → (4.1) roll admin revolts per owned region (ALG-29). Reordering any step invalidates the test.
- **Conquest gating on post-damage military.** Conquest is triggered strictly when post-damage defender military falls below 5.0 (`m + Δm < 5.0`) and the outcome band is not repelled (R-038-01, R-038-02, ALG-22), never on the breakthrough outcome band alone.
- **Garrison sequence.** The garrison (`commit · 0.65`) is added to defender military strictly after attack damage is subtracted, never before (R-038-01).
- **Conquest economy floor bypass.** Conquest disruption (−5.0 economy) can force economy below the 8.0 floor (R-038-01, ALG-22); border friction and passive drift remain clamped at 8.0 (R-041-04, ALG-25).
- **Attacker region isolation.** Attack resolution modifies only the defender's region and the attacker's budget; attacker regions' fields are never altered by combat outcomes (R-037-08, Q-037-01).
- **Draw order.** Tests pin stochastic outcomes with `om_rng_force`, so the order in which the sim consumes uniform draws is part of the contract: per tick, 3d decisions in faction-id order (one draw for telegraph-versus-surprise per attack intent; the attack-confidence roll happens once at faction creation), 3e reinforce (one draw per defender), 3f resolution in target order (collision winner draw, refund draw, then one stochastic draw per applied attack, then the conquest-unrest probability draw and its delay draw, then a colony-penalty draw when the margin is narrow), 4.1 admin rolls in faction-id then region-index order (one draw per owned region, plus the chain-length draw on success). A card that consumes draws in another order fails the forced-draw tests even if every formula is right.

## Edge cases

- **Empty region.** Region count 1 empty neighbor (all fields 0.0, no owner, R-012-07). At tick 10, evaluated by a Conqueror faction (budget 50.0): candidate value is 0, so it is excluded from attack candidates (R-034-03, ALG-11), but enters colonize candidates with strategic position 0.15 (R-034-01). If chosen, colonize costs 20.0 budget and sets fields to 10.0 military, 20.0 economy, 20.0 tension, 25.0 population (R-035-06, R-035-08, ALG-24). A Schism archetype (`can_colonize = no`, R-034-03) ignores the empty region entirely. Border friction never applies to or from the empty region (R-041-05).
- **Floor.** Faction A owns 1 region at economy exactly 8.0 at tick 25. Budget accumulation produces Δbudget = (8.0 − 8.0) · 0.025 = 0.0 (R-033-02); budget remains pinned at 0.0 and never drops below 0. Under border friction with 2 hostile border neighbors, tension increases by +0.30, but economy remains clamped at 8.0 (R-041-04). By contrast, if that region is attacked and conquered at tick 26, conquest disruption subtracts 5.0 economy, bypassing the floor to reach 3.0 (R-038-01). In viability, an attack candidate with net force exactly equal to effective confidence (e.g. net = 5.0, confidence = 5.0) is rejected as not viable (R-035-01). If all action scores are below 0.05 (e.g. attack 0.04, colonize 0.04), the faction accumulates (R-035-07). If colonize wins with budget 19.9 (< 20.0), the faction accumulates (R-035-08). If reactive reinforce calculates commit < 1.0 (e.g. budget 2.0 · 0.30 = 0.60), commit is 0.0 (R-036-05).
- **Max.** Faction A expands to 20 regions at tick 300. Admin revolt excess is max(0, 20 − 4) = 16; revolt roll chance per region is 0.001 + 0.0005 · 16² = 0.129 (12.9% per region per tick, ALG-29, R-040-02). Over 5,000 ticks, no faction holds > 20 regions for > 500 consecutive ticks (Invariants). In combat, a breakthrough attack with net force 80.0 caps tension increase at +30.0 (R-037-04). Against an entrenched defender with military 80.0 held since start (entrenchment 2.0, effective defense 88.0), an attacker committing 50.0 yields net = 50.0 − 88.0 = −38.0 ≤ 0 (repelled); defender loses −0.10 · 50.0 = 5.0 military, tension +2.0, economy delta 0, and no conquest occurs (R-037-05). In reactive reinforce, a home region at military 100.0 or frontier at 60.0 has headroom 0, receiving 0 delta military (ALG-19).
- **Tick 1.** At tick 1, all 15 factions start with budget = 0.0 (R-032-01). Step 3b accumulates the first tick's budget from initial region economies (e.g. regions with economy 66, 40, 9 yield Δbudget = 2.275, R-033-01). The pending telegraph queue is empty at tick 1 start (step 3c resolves nothing). All regions held from world generation have `held_since_tick` unset, giving entrenchment = 2.0 (R-035-01, ALG-13). All pairwise starting stances are hostile (R-032-04). Initial territory counts (home + frontier = 2 regions per faction) are below the admin revolt inflection point of 4, so excess = 0 and chance = 0.001 per region (R-040-01, ALG-29).
- **Concurrent.** At tick 50, three factions (F1 commit 40, economy 200; F2 commit 30, economy 150; F3 commit 20, economy 100) all target the same region 12 in step 3d. Step 3f groups them into a single multi-faction collision (R-039-01, R-039-06, ALG-23); strengths are evaluated simultaneously from step 3a snapshot economies, winner is drawn probabilistically, losers lose full commit and take tension hits on their highest-military regions (R-039-03), and the winner claims the region or colony. Simultaneously on tick 50, F1 attacks F2's region A while F2 attacks F1's region B; both decisions are made from the frozen step 3a snapshot without cross-talk. Multiple regions in a 10-region empire roll admin revolts independently on tick 50 (R-040-02); each successful roll enqueues its own chain for tick 51 independently (R-040-03).
- **Mid-save / load.** At tick 75, the world state is saved with 2 pending telegraphed attacks (due at tick 77 and 78), 1 running admin revolt chain at stage 2, faction budgets at 37.5, attack confidences fixed, and region held-since ticks recorded. Loading the save and running to tick 150 produces a state trace and checksum byte-identical to a continuous run from tick 1 to 150 under the same seed (R4 #18).
- **Post-jump.** Following a time jump of 50 ticks (E-08, tick 100 to 150), all faction budgets, territorial boundaries, and pending queues advance deterministically. If a faction was reduced to 0 regions during the jump, its budget accumulation ceased (R-033-03) and it is evaluated by zombie cleanup (ALG-42). If a region was conquered at tick 120, its entrenchment at tick 150 is 1.0 + (30 / 100) · 1.0 = 1.30 (R-038-05, ALG-13).
- **Pause.** While the simulation pause flag is active, tick loop steps 3 and 4 do not execute: budget deltas are 0, no candidate scoring or decisions occur, no attacks or collisions resolve, border friction deltas are 0, and no admin revolt rolls execute (R4 #17).

## Failure evidence

On any watch-for trip, capture: the world seed; the tick window (the failing tick ± 5); the full `faction_actions`, `attack`, `collision`, `conquest`, `border_friction`, and `admin_revolt` tick log entries across that window; the relevant faction entries (budget, confidence, stance table) and region entries (fields, held-since tick, tier, composites) pre-tick and post-tick; for collision or combat discrepancies, the exact RNG draw sequence, attacker commit, effective attack, effective defense, and net force; for save/load or replay desyncs, both traces aligned by tick. No screenshot is needed (pure T1).
