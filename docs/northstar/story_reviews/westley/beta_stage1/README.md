# B1: the approved screens, walked in a real window

Captured 2026-11-05 from a checkout of main (`OM_BETA=1`, real window on the game monitor, clicks sent through the QA port, pictures taken from the desktop through the screenshot portal and cropped to the game monitor). Every picture was opened and checked: not blank, no desktop notification over it. The console during the walk had no `ERROR` and no `SCRIPT ERROR` line (it did print four harmless `SceneRouter: queued 'main_menu' replaced by 'main_menu'` warnings on boot).

Your own look is still the verdict: press F5 on `project.godot` in your checkout and walk the same chain (privacy, main menu, NEW CAMPAIGN, the mission button, DEPLOY FORCES).
