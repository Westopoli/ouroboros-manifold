# H-081: process-register-and-reaper

"Every process the harness starts is written down with who started it and why, and a finished one is cleaned up by the evidence, not by asking me."

Flag harness; tool Workflow; no scene; Channel: lab. Spec'd 2026-11-03 from Westley's words of 2026-11-03 (DEC-proc-reaper-2026-11-03): "every time there's a lingering process that's obviously done (that I didn't start) you (claude) always asks for permission to kill it. Which is good, but it slows things down. If we more effectively tracked started processes, claude could have the evidence to be sure that it's ok to kill it and not have to ask me. Destructive tasks can be done autonomously if there's guardrails and the scope is specific." After H-077 (the station runs the reaper).

## Why

On 2026-11-03 three `xvfb-run godot` runs from the evening before (worktrees `land-H-067`, `base-H069-probe`) and a `gate-lab.lock` holder whose clerk had ended were found alive and killed only after Westley's word; the Godot runs held graphics memory on a box where every lab landing was waiting on graphics memory. A fourth Godot run (`wt/stack-gate`) was left alone because nobody could say whose it was.

## Rule

A process is killed by an agent only through `proc.py reap`, and `reap` kills only when all three hold: (1) a record exists for the pid; (2) the pid's start time equals the record's (no pid reuse); (3) one of: the owner has ended (a sub-agent whose transcript has its final report after the record's start, or a chat session whose socket is gone), the story has a `Land` commit on main after the record's start, or the record's TTL has passed. A process with no record is never killed by an agent; the agent asks Westley and names which rule fails. Westley's own processes have no record and are untouchable.

## Interfaces (in full)

**Record** `~/Projects/om-push/procs/<pid>.json`: `{"pid": n, "pgid": n, "start": "<btime ticks from /proc/<pid>/stat field 22>", "ts": "<ISO>", "owner": "<agent name or sub-agent id>", "session": "<session id when known>", "story": "<id or ->", "purpose": "<text>", "cmd": ["<argv>"], "ttl_s": n}`.

**`scripts/method/proc.py`** (stdlib only):
- `start --owner <o> [--session <sid>] [--story <id>] --purpose "<text>" [--ttl <s>] -- <command...>`: starts the command in its own process group (`setsid`), writes the record, prints `PROC OK <pid> <purpose>`, and either waits for it (default) or returns at once with `--detach`. Exit code is the child's when waited. DRAFT-proc-ttl 14400 s default.
- `list`: one line per record `PROC <pid> <alive|gone> <owner> <story> <age>s <purpose>`.
- `reap [--dry-run] [--pid <n>]`: for each record: `PROC KEEP <pid> <why>` (`alive owner`, `ttl 3600s left`, `start mismatch`) or `PROC KILL <pid> <evidence>` (`owner ended <when>`, `story landed <sha>`, `ttl passed`); kill is `SIGTERM` to the process group, `SIGKILL` after 10 s, record moved to `procs/reaped/`, one line appended to `procs/reaped.log`: `<ts> <pid> <owner> <story> <evidence> <cmd[0]>`. A pid with no record is reported `PROC KEEP <pid> no record` only when named with `--pid`; `reap` never scans the process table for unrecorded processes.
- Owner liveness: a sub-agent id is ended when a transcript `<id>.jsonl` under `~/.claude/projects/*/subagents/` holds an assistant turn with `stop_reason` `end_turn` after the record's `ts` and no later user turn; a chat is ended when no socket under `/run/user/1000/cc-socks/` belongs to a live pid whose session id matches; `--owner none` records are ended at once (TTL only).

**Hook `.claude/hooks/kill-guard.sh`** (PreToolUse, Bash): denies a command whose segments start with `kill`, `pkill`, `killall`, or `fuser -k`, with `denied: processes are killed through scripts/method/proc.py reap (docs/stories/H-081.md)`; allows `proc.py reap`. `station.py` calls `proc.py reap` once per minute (H-077's loop; one line).

**Callers changed to `proc.py start`**: `clerk.md` step 4 (the gate wrapper, until H-080; then the queue daemon's own runs) and step 5 (`play.sh`); `scripts/specfactory/systemd/om-sweep.service` and `om-nightly-play.service` `ExecStart`; `gate.md`'s detached gate command; any `hold-*` lock holder a clerk starts. `play.sh`, `merge_gate.sh`, `sweep.sh` themselves are unchanged.

## Tests (`tests/method/test_proc.py`, `tests/method/test_kill_guard.py`; a different Sonnet writes them, red on main; temp `OM_PUSH_DIR`, `sleep` children)

1. `start --detach` writes a record whose `start` equals the live `/proc` value and whose `pgid` is the child's.
2. `reap` keeps a record whose owner is alive (fixture transcript with no final report; or a fake socket dir holding the owner); keeps when `start` differs (record edited); keeps with TTL left; prints `PROC KEEP <pid> no record` for `--pid` of a process it did not start and does not kill it (positive control: that process is still alive after).
3. `reap` kills and logs when the owner's fixture transcript ends after the record; when a toy repo gains `Land <story>` after the record; when TTL has passed; one test each, and in each run a second recorded process that must survive does.
4. `reap --dry-run` prints the same lines and kills nothing.
5. The hook denies `kill -9 1234`, `pkill godot`, `fuser -k 8080/tcp`, and `sleep 1; killall x`; allows `python3 scripts/method/proc.py reap` and `pkill` inside a quoted string argument of `grep`.
