# H-077: mail-and-station

"A chat is woken only by its own finished work or by a flag the station raises; everything else waits in its mailbox and is read when it wakes."

Flag harness; tool Workflow; no scene; Channel: lab. Spec'd 2026-11-03 from the plan "the mail-and-station communication method" (Westley approved 2026-11-03; DEC-mail-station-2026-11-03, DEC-wake-classes-2026-11-03). First of five: H-077 this, H-078 nightly numbers, H-079 one Workflow per landing, H-080 gate queue, H-081 process register. Lands before the three chats restart.

## Why

Week of 2026-10-27, measured from the session logs (artifact "Four-Week Harness Report", 2026-11-03): the chat layer (Architect, two Dispatchers) made 3,559 model calls for 38 landings, 94 per landing at a median 168k context, woken 686 times by sub-agent completions and 386 times by cross-chat messages; 643 messages were sent, 153 of them restating what `git log` holds; chats ran 773 state-check commands (`git log`, locks, `status.sh`) that `runner.md` step 3 forbids. Talking, checking state and git were 58% of the week's spend; build plus tests 20% against the 50% rule. The chat layer cost 7x the builder layer per landing.

## Rule (`docs/method/communication.md`, written by this story)

1. **Blackboard first.** State is `git log`, read by `scripts/method/status.sh`. A message that states something git can answer is refused at send. Rulings go into the story file and `decisions.md`; a message about one is a single line pointing there.
2. **Mailboxes** exist only for the named chats in the registry `docs/method/agents.toml`. Sub-agents have none: they report once, their report is the Workflow's return value.
3. **No chat is pushed a message.** A chat wakes on its own background completion or on its flag. Every turn begins with `mail.py read --me <name>`; every turn that leaves work in flight ends with one background `mail.py wait --me <name>`; nothing else is armed. A chat with nothing in flight and an empty inbox stops.
4. **The station** decides every flag; no model does.

## Interfaces (in full)

**Registry `docs/method/agents.toml`** (one table per agent; adding an agent is one table and `mail.py register <name>`):

```toml
[architect]
role = "architect.md"          # the card it reads
rules = true                   # may receive `ask`; a second architect is one more table with rules = true
wake = ["block", "ask", "westley"]   # classes that raise the flag at once; this is the default when absent
linger_min = 20                # optional, overrides DRAFT-mail-linger
batch = 5                      # optional, overrides DRAFT-mail-batch
senders = ["*"]                # "*" or a list of agent names allowed to write here

[runner-lab]
role = "runner.md"
rules = false

[runner-beta]
role = "runner.md"
rules = false

[westley]
role = "westley.md"
rules = false
senders = []                   # nothing writes to him by mail; his words enter as class `westley`
```

**Mail line** (one JSON object per line in `~/Projects/om-push/mail/<agent>/inbox.jsonl`, appended under `flock` on `<agent>/.lock`): `{"id": "<ulid>", "ts": "<ISO-8601 UTC>", "from": "<agent or sub-agent id>", "to": "<agent>", "class": "block|ask|info|westley", "re": "<story id or ->", "text": "<under DRAFT-mail-max>", "attach": ["<path>", ...], "read": null}`. `read` becomes the reading turn's timestamp in `delivered.jsonl`; `inbox.jsonl` holds unread only.

**`scripts/method/mail.py`** (stdlib only; exit 0 ok, 1 refused, 2 usage):
- `register <name>`: makes `mail/<name>/` from the registry table; `MAIL OK registered <name>`; a name not in the registry is refused.
- `send --me <sender> --to <agent>|rules --class <c> [--re <id>] [--attach <path>]... "<text>"`: `--to rules` fans out to every table with `rules = true`. Refusals print `MAIL REFUSED <why>` and append nothing: `blackboard: <pattern>` when the text matches a state-report pattern (`\b(landed|pushed|merged) (at|on|to)?\s*[0-9a-f]{7,}`, `\bslots? (freed|free|held)\b`, `\bin flight\b`, `\bsweep (pass|green|red)\b`, `\bstatus:`); `class ask needs rules = true`; `sender <me> not allowed by <agent>.senders`; `text over <n> chars, put it in a file and --attach it`; `unknown agent <name>`. Success prints `MAIL OK <id> -> <agent> <class>`.
- `read --me <agent>`: prints the digest, one line per unread, `MAIL <class> <from> <re> <ts>: <text first 200 chars> [attach: <paths>]`, moves them to `delivered.jsonl`, prints `MAIL none` when empty. Never blocks. Superseded by H-086 (2026-11-04): the whole text is printed, `read` removes the flag, the last line is `WAIT none` or `WAIT armed <n>`.
- `wait --me <agent> [--max <s>]`: blocks until `mail/<agent>/flag` exists (inotify, else a 2 s poll), removes the flag, then behaves as `read`. Exits 0 with the digest; with `--max` reached prints `MAIL idle <s>s` and exits 0. The only wait a chat may arm; run as a background Bash. Superseded by H-086 (2026-11-04): the poll is 0.25 s; only a wait whose own removal of the flag succeeds returns; the default `--max` is DRAFT-mail-wait-max; a wait whose chat has ended exits silently.
- `list`: the registry as a table (name, role, rules, wake, unread count).

**`scripts/method/station.py`** (daemon, `scripts/specfactory/systemd/om-station.service`, `Type=simple`, `Restart=on-failure`; stdlib only; loop every 2 s, re-reads the registry each loop). For each agent with unread mail it raises `flag` (touch) when any unread has a class in the agent's `wake`, or the oldest unread is older than `linger_min` (DRAFT-mail-linger 20), or the unread count is at least `batch` (DRAFT-mail-batch 5). It never raises a flag that already exists and never reads text. Each raise appends to `~/Projects/om-push/mail/station.log`: `<ts> flag <agent> <reason: class=<c>|linger=<min>|batch=<n>> unread=<n>`. `station.py --once` runs one loop and exits (for tests). From H-081 the loop also runs `proc.py reap`.

**Hook `.claude/hooks/mail-guard.sh`** (PreToolUse, matcher `SendMessage`): reads the tool input, allows `to` equal to `main` or matching `^a[0-9a-f]{8,}` (a sub-agent id) or a known in-process agent name passed by the parent, denies everything else with `denied: cross-chat messages go through scripts/method/mail.py send (docs/method/communication.md)`. Wired in `.claude/settings.json` by the last commit of this story.

**`scripts/specfactory/method_check.py`**: three rules added to `CHECKS`, roles `both`, kind `DRIFT`: `comm_send` (a `SendMessage` whose `to` is not `main` or a sub-agent id), `comm_state_checks` (more than three Bash segments in one wakeup whose command starts with `git log|status|rev-parse|branch`, `status.sh`, `status_check.py`, `flock`, or `ls` on a `.lock`; a wakeup is the span from one user turn to the next), `comm_mail_first` (a wakeup whose first tool call is not `mail.py read`; a wakeup that is Westley's own typed turn is exempt). The `wakeups` rule text gains "or `mail.py wait`"; the `polling` rule exempts a Bash whose command begins `python3 scripts/method/mail.py wait`.

**`scripts/specfactory/status_check.py`**: `STATUS mail DRIFT <agent> <class> unread <min>m` when an inbox holds an unread `block` or `ask` older than 30 minutes (DRAFT-mail-stale 30), `STATUS mail DRIFT sender <name>` when a line's `from` is neither a registry name nor a sub-agent id, else `STATUS mail OK <n> unread`. Exit 1 on DRIFT as today.

## Tests (`tests/method/test_mail.py`, `tests/method/test_station.py`, `tests/method/test_mail_guard.py`, `tests/method/test_method_check_comm.py`; `tests/specfactory/test_status_check.py` gains the mail cases; a different Sonnet writes them, red on main; every test uses a temp `OM_PUSH_DIR` and a fixture registry, never the live `~/Projects/om-push`)

2. `send` appends exactly one line with every field; two concurrent sends append two intact lines (the lock).
3. Each refused pattern refuses, and a positive control with the same words rephrased as a request passes (`"H-057 blocked: needs a ruling on ..."` passes; `"H-057 landed at 1a2b3c4d"` is refused).

5. A sender not in `senders` is refused; `senders = ["*"]` accepts any.
6. Text over DRAFT-mail-max is refused with the attach hint; the same text in a file with `--attach` passes.
7. `read` prints the digest once and moves lines to `delivered.jsonl` with `read` set; a second `read` prints `MAIL none`.
8. `wait` returns when the flag is created by another process, removes the flag and prints the digest; `--max 1` without a flag prints `MAIL idle 1s`.
9. Station `--once` with a fake clock: a `block` raises the flag at once; an `info` does not; five `info` do; one `info` older than `linger_min` does; a raised flag is not raised twice; each raise is one `station.log` line with the reason; per-agent `wake`, `linger_min`, `batch` overrides are honoured.
