## Change

Files: `scripts/play.sh`, `scripts/specfactory/screen_capture.sh`, `docs/method/clerk.md` (step 5), `tests/method/test_play_proof.py` (the writer's).

1. **Idle held off for the play.** From before launch to after the capture `play.sh` holds a GNOME idle inhibitor (session manager `Inhibit` with the idle flag, kept by one helper process that ends with the play, or the builder's measured equivalent) and releases it on every exit path. It changes no setting and leaves no trace after exit. When `org.gnome.ScreenSaver.GetActive` is `(true,)` it prints `PLAY REJECT locked` and launches nothing (DEC-lock-screen-proof-2026-11-02: nothing here ever unlocks or deactivates).
2. **Wake if already dark.** If Mutter IdleMonitor `GetIdletime` is at or above `idle-delay` at play start, the monitors are blank. The builder measures, in order, a harmless key event that reaches Mutter on Wayland, then any other wake that needs neither a consent dialog nor a changed setting, and names the one that works. If none works it prints `PLAY REJECT monitors dark` and captures nothing; the clerk reports "unproven".
3. **Crop to the game monitor.** `play.sh` asks Godot to open on the primary monitor (`--screen` with the primary's index) and `screen_capture.sh` crops the portal PNG to the primary monitor's rectangle, both read from Mutter `DisplayConfig.GetCurrentState` (monitor geometry and the `primary` flag), which works without an X window. The blank metric then runs on the crop, so a dark game monitor is fraction 0 and `CAPTURE REJECT uniform`. The builder checks on this desktop that the primary is the right-hand 2560x1440 monitor, where system notifications also appear (DEC-update-toast-proofs-2026-11-03), and prints the geometry it used on the `CAPTURE` line. If `--screen` does not move the window under the Wayland driver the builder reports it and the crop still applies (the window lands where the compositor puts it; the reviewer judges the primary).
4. **`clerk.md` step 5**: the DEC-wake wording points at `play.sh`; `PLAY REJECT locked` and `PLAY REJECT monitors dark` are reported as "unproven", never as a code red; the look reviewer is told the PNG is one monitor.

## Interim rule until this lands (DEC-proof-wake-crop-2026-11-04)

Before each real-display play the clerk reads `GetIdletime` (Mutter IdleMonitor) and `idle-delay` (gsettings). If idle time is not below `idle-delay` minus DRAFT-play-idle-margin 60 s, it holds the play and reports "unproven: monitors may be dark" (no wake mechanism exists yet). The look reviewer is told to judge the right-hand monitor only and never to quote or copy anything it sees on the other.
