## Build

The clerk's landing, after the push, exports current main with the project's Linux export preset into `~/Projects/om-push/beta/<sha>/` and repoints the symlink `~/Projects/om-push/beta/current` at it. DRAFT: keep the last three builds. The pipe binary (`scripts/build_pipe_linux.sh`) is built alongside and placed where the export expects it. `export_presets.cfg` already has a `Linux` preset with an empty `export_path`; the first piece sets the path and checks the export runs headless. That file is shared, so the edit is its own contract piece.

## Launch

- A desktop entry `~/.local/share/applications/ouroboros-beta.desktop` pointing at `beta/current/<binary>`.
- A one-line command `om-beta` on PATH (DRAFT `~/.local/bin/om-beta`) that runs the same binary under the user's own session env.
- Neither passes a scene argument, so the game boots to its normal first scene.

## Proof

After each refresh the clerk launches the beta under Westley's session env, takes a real screen capture (DEC-play-proof-screen-capture-2026-10-30), and writes the sha and capture path to `~/Projects/om-push/beta/current/PLAYED.txt`. A blank or near-uniform capture is a failed refresh and the symlink stays on the previous build.

## Done when

Westley opens the beta from his desktop and sees the main menu, and the status report says "beta: <sha>, refreshed <date>" from then on.

## Tests

`tests/method/test_beta_build.py`:
- A dry run of the refresh script prints the export and symlink steps.
- The capture check rejects a planted uniform image (positive control).
- The desktop entry file parses and points at an existing path.

## Interfaces (ruled 2026-11-02 for the test writer)

1. **Repo copies.** The desktop entry and the launcher live in the repo as templates: `scripts/beta/ouroboros-beta.desktop` and `scripts/beta/om-beta`. `scripts/beta_refresh.sh` installs them to `$HOME/.local/share/applications/ouroboros-beta.desktop` and `$HOME/.local/bin/om-beta` (mode 755), reading `$HOME` at run time, so tests run it with `HOME=<tmp>` and never touch the real one. The template's `Exec=` and the launcher's binary path point at `$HOME/Projects/om-push/beta/current/ouroboros_beta.x86_64` (the export's output name); the template is validated by a parse (key `Exec`, `Type=Application`, `Name`) and by `Exec` resolving under the refresh script's `--root` override.
2. **Capture check.** `scripts/beta_refresh.sh --check-capture <png>` runs the uniformity check on a given image: exit 0 and the line `CAPTURE OK <fraction>` when the image is not uniform, exit 3 and `CAPTURE REJECT uniform` when it is. It is a thin call into `frame_busyness` from `scripts/specfactory/merge_gate_support.py` (the same function `screen_capture.sh` uses), no copy. The REJECT threshold stays what `screen_capture.sh` has today (blank fraction 0); the real judge of a proof is the Sonnet look reviewer (DEC-play-proof-look-review-2026-11-01), unchanged.
3. **Dry run.** `scripts/beta_refresh.sh --dry-run [--root <dir>] [--tree <dir>] [--sha <sha>]` changes nothing and prints these lines in this order, with the real values substituted (tests match the quoted parts):
   - `DRY export: godot.real --headless --path <tree> --export-release "Linux" <root>/beta/<sha>/ouroboros_beta.x86_64`
   - `DRY pipe: scripts/build_pipe_linux.sh -> <root>/beta/<sha>/ouroboros_pipe`
   - `DRY link: ln -sfn <root>/beta/<sha> <root>/beta/current`
   - `DRY install: <tree>/scripts/beta/om-beta -> $HOME/.local/bin/om-beta`
   - `DRY install: <tree>/scripts/beta/ouroboros-beta.desktop -> $HOME/.local/share/applications/ouroboros-beta.desktop`
   - `DRY keep: last 3 builds under <root>/beta/`
   `<root>` defaults to `$HOME/Projects/om-push`; `export_presets.cfg` Linux `export_path` is set to `dist/linux/ouroboros_beta.x86_64` and the script passes its own explicit output path as above.

4. **GodotSteam binary (ruled 2026-11-02 after the first real export failed).** `.gitignore` excludes `addons/godotsteam/*` except the `.gdextension`, so a fresh export tree has no library and the Linux export fails ("Failed to copy shared object"). `beta_refresh.sh`'s real run first fills `<tree>/addons/godotsteam/` from a cache at `<root>/cache/godotsteam/` when the cache holds the library; on a miss it runs `scripts/fetch_godotsteam.sh` in the export tree (pinned URL, sha256-checked, already tested by `tests/transport/test_fetch_godotsteam.py`) and copies the result into the cache. After the first refresh no network is needed. The beta keeps Steam: its `.pck` must match the shipping build's. The dry run gains a first line, so it prints seven lines: `DRY godotsteam: <root>/cache/godotsteam -> <tree>/addons/godotsteam (on a cache miss: scripts/fetch_godotsteam.sh, sha256-pinned)`, then the six of item 3 in their order. The writer re-pins the line-count and order test as `Test-defect: dry run gains the godotsteam line (H-028 item 4, Westley 2026-11-02 order to make the beta runnable)` with the assertions otherwise unchanged, and adds one test with a scratch tree whose cache holds a planted library: the real run's copy step puts it in `addons/godotsteam/` (the export itself is not run in the test; its proof is the clerk's real export and capture).
5. **Accepted as built:** the installed desktop entry resolves `$HOME` to an absolute path in `Exec=` (the template keeps `$HOME`; a test checks the installed copy is absolute and exists under `--root`); `dist/` joins `.gitignore` (generated output of `build_pipe_linux.sh`; the file joins the list); the proof is two-phase: the clerk runs `beta_refresh.sh` to build into `<root>/beta/<sha>/`, wakes the monitors, launches `<root>/beta/<sha>/ouroboros_beta.x86_64`, captures, then runs `beta_refresh.sh --proof <png>`, which checks the capture, repoints `current` and writes `PLAYED.txt` (sha, capture path, refreshed date); a rejected capture leaves `current` on the previous build. `--sha` defaults to `git -C <tree> rev-parse HEAD`; the writer adds the test for that default (a scratch git repo as `--tree`, no `--sha`, the printed sha equals its HEAD).
