# H-078: nightly-numbers-see-every-directory

"The nightly report counts every session directory of this project and prints how many times a chat woke per landing."

Flag harness; tool Workflow; no scene; Channel: lab. Spec'd 2026-11-03 from the plan "the mail-and-station communication method" (Westley approved 2026-11-03). Independent of H-077; lands first or beside it.

## Why

`scripts/method/token_report.py` (H-003) reads one directory, `~/.claude/projects/-home-westopoli-Projects-ouroboros-manifold`. The 141 `-home-westopoli-Projects-om-push-wt-*` directories hold sessions launched inside worktrees (all from 2026-10-21 to 10-25): for that week the report would have missed 18% of weighted tokens and half the output tokens without saying so. Nothing is missed since 10-27, and nothing warns when it starts again. The report also prints no measure of the thing the communication method changes: chat wakeups per landing (94 in the week of 10-27) and messages per landing (17).

Found while measuring: `~/Projects/om-push/gate_runs.csv` holds 731 week-4 rows written by the gate's own tests (labels `HARNESS-gate-base-after-lock`, 449, and `HARNESS-csim-xdist`, 282) because the tests do not set `MERGE_GATE_RUNS_CSV`; the live log cannot be read for real gate counts.

## Change

1. `token_report.py` scans every `~/.claude/projects/-home-westopoli-Projects-*` directory and keeps a session file when any of its records has `cwd` under `/home/westopoli/Projects/ouroboros-manifold` or `/home/westopoli/Projects/om-push`. It prints one line `TOKENS dirs scanned <n> active <m> skipped <k>` where skipped counts directories that could not be read or whose `cwd` could not be determined; `k > 0` also prints `STATUS tokens DRIFT skipped <k>` and the run exits 1 after writing the row.
2. Two columns are appended to the CSV header and row: `wakeups_per_landing` (assistant turns of non-sidechain sessions in the window, counted once per requestId, divided by the window's `Land` first-parent commits; empty when no landing) and `messages_per_landing` (lines appended to every `~/Projects/om-push/mail/*/inbox.jsonl` plus `delivered.jsonl` with `ts` in the window, divided the same way; 0 before H-077 lands). A third column `dirs` holds `<n>/<m>/<k>`.
3. `status.sh` prints the two new numbers under the four (it reads the CSV).
4. `docs/method/README.md` Numbers gains `DRAFT-wakeups-per-landing | 10 chat turns per Land commit per week | Westley 2026-11-03` and the Status paragraph gains: "Over DRAFT-wakeups-per-landing is a method defect: the Architect names the wake source that grew and proposes the cut."
5. `merge_gate.sh` refuses to append to the default CSV when `MERGE_GATE_TOY=1` is set (prints `GATE row SKIP toy`); `tests/specfactory/gate_toy_root.py` sets `MERGE_GATE_TOY=1` and `MERGE_GATE_RUNS_CSV` to a path under the test's temp dir for every toy run.

## Tests (`tests/method/test_token_report.py` additions, `tests/specfactory/test_merge_gate.py` addition; a different Sonnet writes them, red on main; temp `HOME` and a fixture projects tree)

1. A fixture transcript under a fake `-home-westopoli-Projects-om-push-wt-x` directory with `cwd` `/home/westopoli/Projects/om-push/wt/x` and a timestamp in the window is counted in `weighted_tokens` (positive control: the same transcript under the main directory gives the same total).
2. A fixture transcript under `-home-westopoli-Projects-other` is not counted.

4. On a toy repo with two `Land` commits in the window and a transcript with 40 non-sidechain assistant turns, `wakeups_per_landing` is 20; with no `Land` the field is empty.
5. `messages_per_landing` counts fixture inbox and delivered lines by `ts`.
6. A toy gate run with `MERGE_GATE_TOY=1` prints `GATE row SKIP toy` and leaves the default CSV byte-identical.
