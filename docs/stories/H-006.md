# H-006: the gate without pieces.toml

"The gate reads the story's flag from the story file and the merge message; it needs no pieces row and no owner table, so a story branch lands by itself."

Flag: harness. Tool: Workflow. Branch `s/H-006-gate-story`. First story under the method; it lands through the old gate with one transitional pieces.toml row for itself (id `H-006`, owns the files below), the last row ever added.

## Files

- `scripts/specfactory/merge_gate.sh`: stage 5c owner_lint removed; `PIECES_TOML` and `MERGE_GATE_PIECES` no longer read; the flag stage reads `Flag:` from `docs/stories/<id>.md` on the candidate (a missing line is `sim`); acceptance ids are the `Tests:` paths of the story file; `MERGE_GATE_PIECE_ID` becomes the story id.
- `scripts/specfactory/pre_gate.sh`: owner-row rejects and the `spec_provenance --pieces` step removed; the story's `Tests:` paths run as its own tests.
- `scripts/specfactory/gate_flag.py` and `merge_gate_support.py`: the readers of `impact` from pieces.toml take the story file instead (`story_flag(path)`, `story_tests(path)`); every other function unchanged.
- `tests/specfactory/test_gate_story.py` (new).
- `docs/northstar/plans/push/pieces.toml`: the transitional row only.

## Story file lines the gate reads

```
Flag: harness|client|sim|contract
Tests: <path> [<path> ...]
Scene: res://<path> [args]
```

A story file missing `Flag:` or `Tests:` is `GATE story REJECT missing <key>`.

## Tests

- A fixture candidate with a story file `Flag: client` runs the client tier list and prints `GATE flag client`; `Flag: contract` prints the contract list (positive control: the current `--tier fast` output line for a `harness` fixture is unchanged apart from the source word).
- A fixture with no pieces.toml at all gates to OK (the dependency is gone).
- A diff touching a file no story names is not a reject (owner_lint gone), and the existing footprint fence still rejects a candidate missing the current origin/main (stage 0 unchanged, positive control).
- A story file without `Tests:` rejects with the line above.
