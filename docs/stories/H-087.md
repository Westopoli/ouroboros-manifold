# H-087: beta-runs-on-the-mac

"The godot scene should be runnable from my mac as well, not just linux box." (Westley, 2026-11-05)

Flag client; no tool but the cascade (`docs/method/story_loop.md`); Channel: beta; beta stage B1 with H-060 (plan `docs/northstar/story_reviews/westley/beta-staircase.md`). Ready 2026-11-05 (Westley's go on the B1 plan). Cascade `docs/northstar/plans/cascades/b1-approved-screens/`.

## What it is

On his Mac he pulls the project, runs `scripts/setup_editor.sh` once, opens `project.godot` in Godot 4.6.3 and presses F5, and gets the same chain as on the Linux box (H-060). "Runnable from my Mac" means the editor F5 with a natively built pipe; a signed macOS export is Steam work (ROADMAP section 2), not this story (DEC-mac-is-editor-f5-2026-11-05). Nothing in `autoload/` or `scenes/` changes: `autoload/c_bridge.gd` `_pipe_path()` already resolves `res://pipe/ouroboros_pipe` in the editor, and the pinned GodotSteam zip ships the macOS libraries.

## Rules

- R-087-01 Given `uname -s` is `Darwin`, When `scripts/setup_editor.sh` runs with no pipe or a pipe older than `csrc/`, Then it builds through `scripts/build_pipe_macos.sh` with `ARCH` taken from `uname -m` (`arm64` or `x86_64`) and copies `dist/macos/ouroboros_pipe` to `pipe/ouroboros_pipe` by the same temporary-name-then-move; on Linux nothing changes.
- R-087-02 Given `godot.real` is not on PATH and `/Applications/Godot.app/Contents/MacOS/Godot` exists, When the script runs its import step, Then it uses that binary (the order of `scripts/run_godot_tests.sh`); given neither exists it prints `EDITOR SETUP FAILED import` and names the two places it looked.
- R-087-03 Given `sha256sum` is absent and `shasum` present, When `scripts/fetch_godotsteam.sh` verifies the zip, Then it uses `shasum -a 256` and the pinned sha still gates the unpack; the Linux route is unchanged.
- R-087-04 `scripts/setup_editor.sh --check` on Darwin prints the Darwin build line, the Godot binary it would use, and `clang` present or missing; it changes nothing.
- R-087-05 The README "Open in the editor" paragraph says what a Mac needs (Godot 4.6.3 from godotengine.org in `/Applications`, the Xcode command line tools for `clang`) and that the one command is the same.
