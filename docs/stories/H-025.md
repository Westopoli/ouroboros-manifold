"Layouts are mass-produced from the recorded rules, each with a 3D shot and a predicted verdict, and Westley approves or denies each one with feedback; only approved layouts reach the lab."

Flag client; tool Workflow; Prototype gate for the first page (`docs/method/requirements.md`): judged by eye, Westley approves. Westley, 2026-10-30 (DEC-lab-catalogue-mass-produced-2026-10-30), verbatim: "we need way more, the layout engine is supposed to produce a variety of situations, and with all the different variables this game has (purposefully) to induce strategic depth, it will take some time to clearly define the different situations, but if you take the rules that I've defined and use them to author (mass-produce) positions, and then I get my eyes on them (so long as they have a diagram or godot scene that effectively describes it, a 3D godot screenshot/scene might be better since it's 3D) and your production has a pairing of 'side A wins/side B wins/~draw', I can quickly either approve or deny with feedback each individual one, which would accelerate the process." Land only (DEC-lab-land-first-2026-10-30). ## Layout file

One file per layout, DRAFT path `docs/northstar/research/layer_dynamics/catalogue/<id>.toml`:
- Situation kind: chokepoint, vantage, cover, objective, staging, flank route, trap, and more from the E-17 node kinds.
- Landscape piece; each side's units with role, position, facing, layer.
- `predict = "A" | "B" | "draw"` with one sentence why (the Architect's prediction).
- `verdict = ""` filled by Westley on review, and a `feedback` line.

## Producer

A script that, from the rules in the bible epics E-01 and E-17 and the recorded positioning rules, generates layouts across situation kinds and headcount pairs within 8 to 256 per side. DRAFT first batch: 30 layouts.

## Shot

A Godot scene, `res://scenes/proto/layout_shot/layout_shot.tscn` (DRAFT path), built on `scenes/ground3d/`: loads a layout file and renders it in 3D with sides coloured, facing arrows, layer visible and unit type legible, and saves one PNG per layout.

## Review

A page listing every layout with its shot and predicted verdict; approve or deny with feedback per row. The clerk writes his verdicts back into the files and a `Seen` note. Denied layouts return to the producer with the feedback.

## Done when

The first batch is reviewed and at least one layout is approved.

## Tests

- The producer emits valid files across every situation kind.
- A planted rule contradiction is rejected (positive control).
- The shot scene's `qa_state()` inventory lists every unit and the legend.
- The review page writes verdicts back.
