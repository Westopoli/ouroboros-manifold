# H-071: review-apply-reads-the-verdict-words

"The catalogue applies the verdicts as written."

Flag harness; tool Workflow; no scene. Spec'd 2026-11-02; Channel: lab; becomes Ready after the lab's stack landing. Found by the verdict-recording investigation of 2026-11-02 (DEC-verdict-ledger-2026-11-02).

## Why

Westley, 2026-11-02: "L37 through 48 I've already ruled on, if you didn't catch that then there's a gap in the way we're recording approved/denied + feedback documentation from screenshots". The engineer's investigation of the chat transcripts found three gaps. This story closes the third, the one in code.

- The round-two verdicts (L-0037 to L-0047, and the hold on L-0048) are recorded in `docs/northstar/research/layer_dynamics/catalogue/verdicts.md` (lines 54 to 76), with his words, but 17 rows use `hold`, `redraw` or `out`.
- `scripts/skilllab/catalogue/review.py` accepts only `VERDICTS = ("A", "B", "draw", "deny")`. `review.py apply` on the real file prints `bad verdict rows` and writes nothing, so the 12 round-two layout tomls (L-0037 to L-0048) still carry `verdict = ""` and `review.py denied` lists none of the round-two denies.
- The header of `verdicts.md` claimed "the words `review.py` accepts"; it now states the truth and names this story.

The other two gaps were records, not code, and are closed by DEC-verdict-ledger-2026-11-02: `ruled.md` is the one verdict ledger, and L-0048 was never ruled (his only words were a question; the re-send promised on 2026-11-01 is owed and now waits for his verdict).

## Change

1. `review.py apply` accepts the seven words A, B, draw, deny, hold, redraw and out.
2. When a layout id has several rows, the last row wins (the amended-row rule that `verdicts.md` already states and `ruled.md` relies on).
3. `apply` writes the winning verdict and feedback into each layout toml's `verdict` and `feedback` fields (it already does so through `write_layout`; the change is that it now reaches that line for the real file).
4. An unknown id or an unknown word is rejected with the line number of the row in the verdicts file, and nothing is written.
5. `review.py denied` then lists the round-two denies (L-0039, L-0047 and the batch-one rows) from the tomls.

Not in this story: any change to the verdict wording of a row, the pictures, or the layouts themselves.

## Tests

`tests/skilllab/test_review_apply_words.py` (new; a different Sonnet writes it, red on main).

1. A verdicts file holding one row for each of the seven words applies, and each toml carries its word.
2. An amended row (same id, later line) wins: a file with L-0001 `A` then L-0001 `deny` leaves `deny`.
3. An unknown word is rejected with the line number of its row, and no toml is written.
4. Positive control: the current `docs/northstar/research/layer_dynamics/catalogue/verdicts.md`, applied to a scratch copy of the catalogue (`tmp_path`), applies cleanly and `denied` lists L-0039 and L-0047.

## Files

- `scripts/skilllab/catalogue/review.py`: the `VERDICTS` tuple, `_rows` (line numbers) and `apply` (last row wins).
- The layout toml files of the catalogue (pattern, plain text: docs/northstar/research/layer_dynamics/catalogue/L-*.toml): rewritten by `apply` when the sweep or Westley runs it; the story's test works on a scratch copy.
