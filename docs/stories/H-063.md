## What stage 3 adds (and nothing else)

- **The layout's features become obstacles for the sim.** Chokepoint walls, city buildings, cover boxes as movement blocks (sight through them is stage 4), the flank ridge as an engine block until stage 5 (DEC-ridge-block-until-stage5-2026-11-05), a slope band with `OM_TP_SLOPE_UP_DIV` (R-001-06 and R-001-07: terrain tiers, not planes). Feature kinds follow the H-025 round-two schema. Hazard discs and the vantage's second visual band stay drawn only (stage 7).
- **The runner REJECTs a layout whose attackers cannot reach the orders point**, naming the first unreachable unit (rule R8 in `scripts/skilllab/catalogue/rules.toml`, checked by `scripts/skilllab/arena/run.py`, not by `check_layout`). The route grid is the engine's: 50 wu cells with the engine's round-out of every block rectangle, plus the engine's walk mask for a slope (DEC-stage3-reach-engine-rule-2026-11-05).
- **Replay draws the same geometry** as the layout shot under the units, on the fight's own landscape (`landscape` key in the fight file; `small_tiered` for a slope); the stage 2 readability rules carry over.
- **Layouts (DEC-stage3-layouts-2026-11-05, his 2026-11-01 words):** chokepoint L-0055 (blue 98%), city L-0073 (blue 75%), slope L-0084 (blue 60%, redrawn from SIT-0109), cover L-0039 as drawn (red 75%, so blue 0.25). Four fights, twenty seeds each (DRAFT-seeds-per-layout), the percentage a heuristic target and unscored.
- **Sight stays off** (`OM_TP_TARGET_BY_SIGHT` 0), abilities off, engine rules of H-057. Orders per H-052. Scoring as ruled 2026-11-02.
- **What the pictures show him:** where the geometry slows or stops a unit (a marker on units blocked more than 2 s, and a blocked count in the HUD, the results table and the page), and the same fight without the geometry as a control strip. The control fight keeps the units walking, only the `features` are emptied, and the replay draws it without walls.

## Known limits (builder findings, 2026-11-02)

- (c) Slope heights are built only for heading 0 and bands 0 to 1 (every catalogue slope); any other raises ValueError. A new slope kind needs its own story.
- (d) Slope plus planar blocks: the terrain walk planner ignores block_rect, so on a slope layout only planar blocks apply to the collision grid. No slope-plus-wall picture goes to Westley as if walls applied.
- (e) The reachability check routes over the ribbon as the only way up and treats a cell as open when any layer's walk mask is set there (DRAFT-reach-mask-union); a layout the engine's planner would refuse for a finer reason passes it.
