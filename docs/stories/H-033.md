# H-033: nightly-play-git-path

"The nightly play files what it found as harness rows on a branch every night; a finding never dies in the timer's journal."

Gate flag harness; tool Workflow; branch `s/H-033-nightly-play-git-path`. Found 2026-10-31 in the journal of `om-nightly-play.service` (2026-10-30 23:01): `scripts/method/file_findings.py` line 23 sets `repo = doc.resolve().parent`, which for `docs/method/harness.md` is `docs/method`, not the repository root; line 26 then runs every git command as `git -C <repo>/docs/method ...`, and the `add` at line 42 passes the path `docs/method/harness.md` relative to that directory, so git prints `warning: could not open directory 'docs/method/docs/method/'` and `fatal: pathspec 'docs/method/harness.md' did not match any files`; the service exits 1 and the night's findings are not filed. The checkout at line 29 happened to work because `git checkout` takes no path. One cause, one fix.

## Files

- `scripts/method/file_findings.py`: `repo` is the repository root (the top of `git rev-parse --show-toplevel` run beside the doc, or `doc.resolve().parents[1]` when the doc is `docs/method/harness.md`; the builder picks one and says which in a comment), and the `add` passes the doc's path relative to that root. No other change; the row format and the branch name stay.
