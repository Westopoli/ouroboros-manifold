### Interfaces (fixed)

Trace row: `(tick, unit, x, y, target, facing, alive, layer, unit_type)`, nine fields. `layer` and `unit_type` are appended after `alive` and read in `fight.py` `record()` through `engine.unit_layer(w, u)` (`engine.py:324`) and `engine.unit_type(w, u)` (`engine.py:360`). `contract.py` line 114 documents the nine fields. A dead unit keeps its last layer and type, like its position.

Validator: new module `scripts/skilllab/trace_rows.py`.
- `validate_row(row: tuple) -> None` raises `ValueError("trace row needs 9 fields, got <n>")` on any other length, and `ValueError("trace row field <name> bad: <value>")` when tick, unit, target, layer or unit_type is not an int, x, y or facing is not a float or int, or alive is not a bool or 0/1.
- `validate_trace(rows: list) -> int` validates each row and returns the row count.
- The lab calls `validate_trace` once per fight when `Setup.trace` is on.

Sampler: new module `scripts/skilllab/snapshots.py`.
- `first_contact_tick(rows, side_a: set[int], side_b: set[int]) -> int | None`: the first tick at which any row with `alive` true has a `target` that is a member of the other side's id set (a side A unit targeting a side B id, or the reverse); dead rows carry `target` 0 and are skipped; None when it never happens. Reason: `om_unit_get_target` returns `row->target_id` or 0 (csrc/unit.c:2830), and `fight.py` `record()` writes 0 for dead rows, so a sign test cannot work.
- `sample_ticks(first: int, last: int, contact: int | None, n_even: int = 12, offsets: tuple = (-20, -10, 10, 20)) -> list[int]`: even ticks are `round(first + k * (last - first) / (n_even - 1))` for k in 0..n_even-1 (all `first` when n_even is 1); contact ticks are `contact + o` for each offset when contact is not None; the result is clipped to [first, last], deduplicated and sorted ascending.

qa_state inventory: parked until the builder's scene exists; written as a round-2 test after the first screenshot, with keys DRAFT `scene`, `replay_fps`, `shot_ticks` (list of int), `unit_count`, `layers_visible` (bool).
