# H-041: unit-scale-readthrough (contract)

"The radius I locked per role in the values file is the radius the game uses, so a layout's spacing and a fight's collisions follow my numbers, not a constant in C."

Flag contract; tool Workflow. Spec'd 2026-11-01, not Ready: `data/unit_scale.toml` still holds its drafts (every role radius 15.000, visual_scale 1.000, equal to `OM_UNIT_COLLISION_RADIUS 15`, `csrc/om_constants.h:581`); Westley's per-role tuning session is still owed (DEC-unit-scale-tuning-owed-2026-11-01). This story becomes Ready the day his session writes the file, and lands before any consumer of the new values.

## Contract change (lands first, documented here)

- `csrc/ouroboros_sim.h`: `int om_roster_set_collision_radius(om_world *w, int unit_type, double radius);` beside `om_roster_set_reach` (line 2008). Returns 0, or -1 for an unknown type or a radius outside DRAFT-radius-bounds 1 to 200. Recorded in `signatures.toml`.
- The per-type radius replaces `OM_UNIT_COLLISION_RADIUS` at its eleven use sites (`csrc/unit.c:2579`, `tactical_move.c:95,96,390`, `mission.c:2470,2743`, `enemy_macro.c:964,965`, and the spacing comments); a site that has no unit type in hand (grid cell size, margins) uses the roster's largest radius. `OM_TP_UNIT_COLLISION_RADIUS` (world-wide tuning knob, `ouroboros_sim.h:1021`) keeps working as a multiplier on the per-type value; its reading is documented at the knob.
- Determinism: the radius is read once at `om_roster_*` time, never from the file inside the tick.

## Consumers (after the contract lands)

- `autoload/c_bridge.gd` (or the pipe handler that registers the roster) reads `data/unit_scale.toml` at boot and calls the new function per role; a missing file or key keeps 15 with one warning line.
- `scripts/skilllab/engine.py` binds the function; `fight.py` `_register_types` calls it from the same file.
- `scripts/skilllab/catalogue/rules.toml` R2 `min_spacing` becomes "two radii of the larger role" computed by `check_layout` from the file; the 40 wu block pitch in H-025 round two and H-040 part 5 becomes DRAFT-block-pitch = 2 x largest radius + 10.
- The catalogue is regenerated once; Westley's verdicts carry over by id.

## Tests
