# Skill lab (the SPACE lab)

This lab measures layer-system skill for space eras (the Settled Reach). Space means: five free layers, every unit flies, terrain blocks per layer range, cover discs, the ping; passive sight across layers is very limited (Q-005-07). Spec: `docs/northstar/plans/2026-10-05-space-lab-stage1-spec.md`. State and plan: `docs/northstar/research/layer_dynamics/README.md` ("Two labs").

The ground lab is parked under `ground/` until the sim has ground. Nothing in `ground/` is a ground answer.
